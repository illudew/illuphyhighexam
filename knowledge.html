🪐 力学

9 节

高考物理的绝对主干：从运动描述到牛顿定律，从曲线运动、万有引力到功与能、动量，约占全卷 45%。

1.1运动的描述与匀变速直线运动

建立质点、参考系、位移、速度、加速度等基本概念，掌握匀变速直线运动的公式、推论与运动图象。

1质点、参考系与位移

当物体的大小和形状对研究问题的影响可以忽略时，可把物体简化为有质量的点，即质点。描述运动必须选定参考系；位移是矢量，方向由初位置指向末位置，$x-t$ 图象的斜率表示速度。

位移定义$$\Delta x = x_2 - x_1$$矢量，与路径无关
平均速度$$\bar{v} = \frac{\Delta x}{\Delta t}$$方向与位移方向相同
平均速率$$v = \frac{s}{t}$$路程与时间之比，标量
  • 位移是矢量、路程是标量，二者只在单向直线运动中大小相等。
  • $x-t$ 图线的斜率表示速度，图线交点表示两物体相遇。
易错提醒｜求平均速度必须用位移除以时间，不能错用路程除以时间；注意速度与速率的区别。

2加速度与速度—时间图象

加速度描述速度变化的快慢，是速度变化量与所用时间的比值，方向与速度变化量方向相同。$v-t$ 图象的斜率表示加速度，图线与时间轴所围面积表示位移。

加速度定义$$a = \frac{\Delta v}{\Delta t} = \frac{v - v_0}{t}$$矢量，方向同 $\Delta v$
图线面积$$x = \frac{v_0 + v}{2}\,t$$$v-t$ 图线与时间轴所围面积
  • 加速度方向与速度方向相同则加速，相反则减速，与加速度的增减无关。
  • $v-t$ 图象斜率的正负表示加速度方向，而不是速度方向。
易错提醒｜加速度大不代表速度大；速度为零时加速度可以不为零（如竖直上抛的最高点）。

3匀变速直线运动三大公式

加速度恒定的直线运动称为匀变速直线运动。规定初速度方向为正方向后，用带正负号的标量即可表示各矢量的方向。

速度公式$$v = v_0 + at$$不含位移 $x$
位移公式$$x = v_0 t + \tfrac{1}{2} a t^{2}$$不含末速度 $v$
速度位移关系$$v^{2} - v_0^{2} = 2ax$$不含时间 $t$
  • 三个公式共涉及五个量，已知任意三个可求其余两个。
  • 先规定正方向，把矢量代成带正负号的标量，可避免分类讨论。
易错提醒｜刹车类问题要先求出停止所需时间，实际运动时间可能小于题目给定时间，不可盲目代入公式。

4匀变速运动的常用推论

由三大基本公式可导出多个推论，用于快速求解中间时刻速度、中间位置速度以及纸带实验中的逐差问题。

中间时刻速度$$v_{t/2} = \bar{v} = \frac{v_0 + v}{2}$$等于该段过程的平均速度
中间位置速度$$v_{x/2} = \sqrt{\frac{v_0^{2} + v^{2}}{2}}$$恒有 $v_{x/2} \geq v_{t/2}$
逐差相等$$\Delta x = x_{n+1} - x_n = aT^{2}$$纸带求加速度常用
  • 无论匀加速还是匀减速，恒有中间位置速度不小于中间时刻速度。
  • 连续相等时间间隔内的位移差恒为 $aT^{2}$，可用于求加速度。
易错提醒｜逐差公式要求各段时间相等；对初速度为零的匀加速，位移比才满足 $1:3:5:\cdots$。

5自由落体与竖直上抛

只受重力、初速度为零的下落是自由落体运动，加速度为重力加速度 $g$；竖直上抛运动可看作向上的匀减速与向下的自由落体，具有对称性。

自由落体速度$$v = gt$$取竖直向下为正方向
自由落体位移$$h = \tfrac{1}{2} g t^{2}$$同理有 $v^{2} = 2gh$
上抛最大高度$$h = \frac{v_0^{2}}{2g}$$竖直上抛上升的最大高度
  • 竖直上抛上升与下降过程具有时间、速率对称性，全程可视为加速度为 $-g$ 的匀变速运动。
  • 最高点速度为零但加速度仍为 $g$，不是平衡状态。
易错提醒｜忽略空气阻力时才能当作自由落体；上抛物体返回抛出点时速度大小等于初速度。

6运动图象的识别

借助 $x-t$、$v-t$ 图象可以把运动规律直观化，识图的关键是弄清斜率、截距与面积的物理意义。

$x-t$ 斜率$$v = \frac{\Delta x}{\Delta t}$$切线斜率表示瞬时速度
$v-t$ 斜率$$a = \frac{\Delta v}{\Delta t}$$斜率表示加速度
  • $x-t$ 图线是曲线时表示变速运动，切线斜率仍表示该时刻的瞬时速度。
  • $v-t$ 图线在时间轴下方的面积表示负方向的位移。
易错提醒｜图象不是运动轨迹；$x-t$ 与 $v-t$ 的纵轴含义不同，不可混淆。

1.2相互作用：重力、弹力与摩擦力

认识常见的三种力，掌握重力与重心、弹力的判断与胡克定律、静摩擦力与滑动摩擦力的特点。

1重力与重心

由于地球的吸引而使物体受到的力叫重力，方向竖直向下；重力的等效作用点叫重心，其位置由物体的质量分布和形状决定。

重力$$G = mg$$方向竖直向下
重心坐标$$x_{c} = \frac{\sum m_i x_i}{\sum m_i}$$由质量分布决定
  • 重力由万有引力引起，但通常略小于万有引力。
  • 重心可以在物体之外，例如圆环的重心在圆心。
易错提醒｜重力方向是竖直向下而非垂直向下；同一物体在不同纬度的重力略有不同。

2弹力与胡克定律

发生形变的物体要恢复原状，会对与之接触的物体产生弹力。弹簧的弹力与形变量成正比，方向沿弹簧轴线。

胡克定律$$F = kx$$只在弹性限度内成立
劲度系数$$k = \frac{F}{x}$$单位 $\mathrm{N/m}$，由弹簧本身决定
  • 绳的拉力只能沿绳指向绳收缩的方向，杆的弹力方向不一定沿杆。
  • 接触面间的压力属于弹力，方向垂直接触面。
易错提醒｜胡克定律只在弹性限度内成立；弹簧被压缩与拉伸时 $x$ 均取形变量的大小。

3静摩擦力

两物体接触且有相对运动趋势但未发生相对滑动时，接触面间的摩擦力叫静摩擦力，其大小随外力变化，方向与相对运动趋势方向相反。

静摩擦力范围$$0 \leq f \leq f_{\max}$$具体大小由平衡条件求解
最大静摩擦力$$f_{\max} = \mu_s N$$近似等于滑动摩擦力
  • 静摩擦力大小由平衡条件或牛顿定律确定，不能用 $f = \mu N$ 计算。
  • 静摩擦力可以是动力；摩擦力方向与相对运动（趋势）方向相反，不一定与运动方向相反。
易错提醒｜判断静摩擦力方向要看相对运动趋势，而非物体的绝对运动方向；静止的物体也可能受摩擦力。

4滑动摩擦力

两物体间发生相对滑动时，接触面间的摩擦力叫滑动摩擦力，其大小等于正压力与动摩擦因数的乘积，方向与相对滑动方向相反。

滑动摩擦力$$f = \mu N$$$\mu$ 为动摩擦因数
动摩擦因数$$\mu = \frac{f}{N}$$无单位，由材料和粗糙程度决定
  • 滑动摩擦力大小只与 $\mu$ 和正压力 $N$ 有关，与接触面积、相对速度无关。
  • 正压力 $N$ 不一定等于重力，需由受力分析确定。
易错提醒｜滑动摩擦力方向与相对滑动方向相反；不要把 $N$ 一律当作重力 $mg$。

5弹力有无与方向的判断

判断弹力是否存在的常用方法是假设法：撤去接触物，若物体的运动状态改变则有弹力，否则没有。

轻绳张力$$T = T'$$同一根轻绳中张力处处相等
接触面弹力$$N \perp \text{接触面}$$方向垂直接触面指向被压物体
  • 理想轻绳、轻杆、轻弹簧的质量不计，绳只能拉不能压，杆和弹簧既可拉也可压。
  • 判断弹力有无常用假设法或状态法。
易错提醒｜接触不一定有弹力；有弹力必然接触且发生弹性形变。

1.3牛顿运动定律

掌握牛顿三定律的内容，学会用整体法、隔离法进行受力分析并处理超重失重等动力学问题。

1牛顿第一定律与惯性

一切物体总保持匀速直线运动状态或静止状态，直到有外力迫使它改变这种状态为止。物体保持原有运动状态的性质叫惯性。

惯性大小$$m = \frac{F}{a}$$质量是惯性大小的唯一量度
  • 力是改变物体运动状态的原因，不是维持运动的原因。
  • 质量是惯性大小的唯一量度，与速度无关。
易错提醒｜惯性是物体的固有属性，不能说物体受到惯性作用或受到惯性力。

2牛顿第二定律

物体加速度的大小与所受合外力成正比、与质量成反比，加速度方向与合外力方向相同。

牛顿第二定律$$F_{\text{合}} = ma$$矢量式，方向同合外力
分量式$$F_x = m a_x,\quad F_y = m a_y$$正交分解后分别列式
  • $F = ma$ 是瞬时对应关系，合力与加速度同时产生、同时变化、同时消失。
  • 解题时对每个物体分别列牛顿第二定律，必要时进行正交分解。
易错提醒｜合外力与加速度方向必然相同；合外力为零时加速度为零，物体处于平衡或匀速状态。

3牛顿第三定律

两个物体之间的作用力和反作用力总是大小相等、方向相反、作用在同一直线上，分别作用在两个物体上。

牛顿第三定律$$F = -F'$$作用力与反作用力等大反向
  • 作用力与反作用力同时产生、同时消失，作用在不同物体上，不能求合力。
  • 一对平衡力作用在同一物体上，可以求合力，二者性质不同。
易错提醒｜不要把作用力与反作用力当作平衡力；二者虽等大反向，但作用对象不同。

4超重与失重

当物体具有竖直向上的加速度时，支持面或绳对物体的作用力大于重力，称为超重；加速度竖直向下时称为失重；当加速度等于 $g$ 且竖直向下时称为完全失重。

超重视重$$N = m(g + a)$$加速度方向竖直向上
失重视重$$N = m(g - a)$$加速度方向竖直向下
  • 超重、失重看的是加速度方向，与速度方向无关。
  • 完全失重时一切与重力有关的现象消失，如天平失效。
易错提醒｜超重并不是重力变大，物体的重力始终为 $mg$；升降机匀速运动时既不超重也不失重。

5连接体问题与整体法、隔离法

多个物体通过绳、杆或接触面连接而成的系统称为连接体。可先用整体法求系统加速度，再用隔离法求内力。

整体加速度$$a = \frac{F_{\text{外}}}{m_1 + m_2}$$由系统所受外力求整体加速度
隔离求内力$$T = m_2 a$$对系统某一部分用牛顿第二定律
  • 加速度相同的系统可先用整体法求加速度，再用隔离法求内力。
  • 整体法只考虑外力，隔离法可分析系统内部的相互作用力。
易错提醒｜整体法不能求系统内部的相互作用力；方法的选择要看求解的是外力还是内力。

1.4曲线运动与抛体运动

理解曲线运动的条件，掌握运动的合成与分解、小船渡河、平抛与斜抛运动的规律。

1曲线运动的条件与速度方向

物体做曲线运动时，速度方向沿轨迹在该点的切线方向；当合外力方向与速度方向不在同一直线上时，物体做曲线运动。

速度方向$$\vec{v} \parallel \text{轨迹切线}$$曲线运动是变速运动
  • 曲线运动一定是变速运动，但它可以是匀变速运动，如平抛运动。
  • 合外力方向指向轨迹弯曲的凹侧。
易错提醒｜曲线运动的速度方向时刻改变，一定存在加速度；速度方向与合外力方向不平行。

2运动的合成与分解

一个运动可以分解为几个分运动，各分运动具有独立性（互不影响）和等时性。位移、速度、加速度均按平行四边形定则合成。

速度合成$$\vec{v} = \vec{v}_1 + \vec{v}_2$$遵循平行四边形定则
位移合成$$\vec{s} = \vec{s}_1 + \vec{s}_2$$合运动与分运动等时
  • 分运动相互独立、运动时间相同。
  • 合运动与分运动的位移、速度关系遵循平行四边形定则。
易错提醒｜分解时按运动效果分解，不可随意正交分解；小船渡河问题中合速度由各分速度合成。

3小船渡河与关联速度

小船渡河的最短时间由船在静水中垂直河岸的分速度决定；关联速度问题中，绳（杆）两端沿绳（杆）方向的分速度大小相等。

最短渡河时间$$t_{\min} = \frac{d}{v_{\text{船}}}$$船头垂直河岸，与水流无关
最短渡河位移$$s_{\min} = \frac{d}{\cos\theta}$$需 $v_{\text{船}} \geq v_{\text{水}}$
  • 渡河时间最短时船头垂直河岸，与水流速度无关。
  • 关联速度中沿绳（杆）方向的分速度相等。
易错提醒｜渡河位移最短与时间最短是两种不同的要求，不能用同一种分解方式处理。

4平抛运动

水平抛出、只受重力的运动为平抛运动，可分解为水平方向的匀速直线运动和竖直方向的自由落体运动。

水平方向$$x = v_0 t$$水平方向匀速
竖直方向$$y = \tfrac{1}{2} g t^{2}$$竖直方向自由落体
速度偏角$$\tan\theta = \frac{v_y}{v_x} = \frac{gt}{v_0}$$$\theta$ 为速度与水平方向夹角
位移偏角$$\tan\alpha = \frac{y}{x} = \frac{gt}{2v_0}$$$\alpha$ 为位移与水平方向夹角
  • 平抛运动的时间只由下落高度决定，即 $t = \sqrt{2h/g}$。
  • 速度偏角的正切是位移偏角正切的二倍，即 $\tan\theta = 2\tan\alpha$。
易错提醒｜平抛的水平位移与初速度和高度都有关；飞行时间只由高度决定，与初速度无关。

5斜抛运动

以一定初速度斜向上抛出、只受重力的运动为斜抛运动，可分解为水平方向的匀速运动和竖直方向的匀变速运动。

射高$$H = \frac{v_0^{2}\sin^{2}\theta}{2g}$$最高点竖直分速度为零
射程$$R = \frac{v_0^{2}\sin 2\theta}{g}$$初末高度相同时的水平射程
飞行时间$$T = \frac{2v_0 \sin\theta}{g}$$初末等高时的滞空时间
  • 斜抛运动水平方向速度不变，竖直方向做加速度为 $g$ 的匀变速运动。
  • 初末高度相同时，$\theta = 45^{\circ}$ 时射程最大。
易错提醒｜斜抛的射程公式仅在初末高度相同时成立；上升与下降过程具有对称性。

1.5圆周运动

掌握线速度、角速度、周期与向心加速度的关系，会用牛顿第二定律分析向心力与竖直圆临界问题。

1线速度、角速度与周期

描述圆周运动快慢的物理量有线速度、角速度、周期和频率，它们之间通过半径相互联系。

线速度$$v = \frac{2\pi r}{T} = \omega r$$方向沿切线
角速度$$\omega = \frac{2\pi}{T} = 2\pi f$$单位 $\mathrm{rad/s}$
转速关系$$n = f = \frac{1}{T}$$转速单位 $\mathrm{r/s}$
  • 同一转轴上各点的角速度相同；皮带（齿轮）传动时边缘线速度大小相同。
  • 线速度方向时刻沿切线，因此圆周运动是变速运动。
易错提醒｜同轴转动角速度相同、线速度与半径成正比；皮带传动线速度相同、角速度与半径成反比，要区分。

2向心加速度与向心力

做圆周运动的物体所受指向圆心的合外力叫向心力，它只改变速度方向而不改变大小，所产生的加速度叫向心加速度。

向心加速度$$a_n = \frac{v^{2}}{r} = \omega^{2} r$$方向指向圆心
向心力$$F_n = m\frac{v^{2}}{r} = m\omega^{2} r$$由合外力提供
  • 向心力是效果力，由重力、弹力、摩擦力等的合力提供。
  • 匀速圆周运动的合外力完全提供向心力，方向指向圆心。
易错提醒｜向心力不是额外的、独立存在的力；受力分析时不能凭空多画一个向心力。

3水平面内的匀速圆周运动

常见的水平圆运动有转盘上的物体、圆锥摆等，向心力由摩擦力或绳的拉力的水平分量等提供。

转盘临界$$\mu mg = m\omega^{2} r$$静摩擦力提供向心力
圆锥摆$$mg\tan\theta = m\omega^{2} L\sin\theta$$$L$ 为摆线长度
  • 圆盘上物体即将滑动时，静摩擦力达到最大值。
  • 分析圆周运动先找圆心、半径，再沿半径方向列向心力方程。
易错提醒｜向心力方程应沿半径方向列式，不能把向心力当作竖直方向的力。

4竖直平面内的圆周运动与临界条件

竖直圆运动中，绳（轨道内侧）约束下最高点存在最小速度；杆（轨道内外侧）约束下最高点速度可以为零。

绳模型最高点$$mg = m\frac{v_{\min}^{2}}{r}$$最小速度 $v_{\min} = \sqrt{gr}$
杆模型最高点$$v_{\min} = 0$$杆可提供支持力
最低点$$F - mg = m\frac{v^{2}}{r}$$绳的拉力大于重力
  • 轻绳（内轨）模型过最高点的条件为 $v \geq \sqrt{gr}$。
  • 轻杆（双轨）模型过最高点的条件为 $v \geq 0$。
易错提醒｜区分绳模型与杆模型的临界条件；杆在最高点可以提供向上的支持力，绳不能。

5离心运动

当外界提供的向心力突然消失或不足时，物体将沿切线飞出或做逐渐远离圆心的运动，称为离心运动。

向心力不足$$F_{\text{供}} \leq m\omega^{2} r$$物体做离心运动
供需相等$$F_{\text{供}} = m\omega^{2} r$$维持圆周运动
  • 离心运动的原因是向心力不足，而不是受到离心力。
  • 向心力突然消失时物体将沿切线方向飞出。
易错提醒｜离心运动应解释为外力不足以提供向心力，物理学中不存在离心力的作用。

1.6万有引力与航天

掌握万有引力定律及其在天体运动中的应用，理解天体质量估算、宇宙速度与人造卫星规律。

1开普勒三定律

描述行星运动的规律：轨道定律（椭圆轨道）、面积定律（相等时间扫过相等面积）、周期定律（半长轴的立方与周期的平方成正比）。

开普勒第三定律$$\frac{a^{3}}{T^{2}} = k$$$k$ 只与中心天体有关
面积定律$$\frac{\Delta S}{\Delta t} = \text{常量}$$近日点速率最大
  • 行星在近日点速率最大，在远日点速率最小。
  • 周期定律中的 $k$ 由中心天体质量决定，与环绕天体无关。
易错提醒｜开普勒第三定律对绕同一中心天体的所有卫星都成立，不同中心天体的 $k$ 不同。

2万有引力定律

任何两个物体之间都存在相互吸引的万有引力，大小与两物体质量的乘积成正比，与它们之间距离的平方成反比。

万有引力定律$$F = G\frac{m_1 m_2}{r^{2}}$$$G = 6.67\times10^{-11}\,\mathrm{N\cdot m^{2}/kg^{2}}$
黄金代换$$GM = gR^{2}$$星球表面重力与引力关系
  • 万有引力公式中的 $r$ 是两质点间的距离，对均匀球体是两球心间的距离。
  • 忽略星球自转时，星球表面物体的重力近似等于万有引力。
易错提醒｜$r$ 不是两物体表面间的距离；引力常量由卡文迪什扭秤实验测得。

3天体质量与密度的估算

利用环绕天体的运动参量（周期、轨道半径、线速度）可以估算中心天体的质量与密度。

求中心天体质量$$M = \frac{4\pi^{2} r^{3}}{G T^{2}}$$已知卫星轨道半径与周期
天体密度$$\rho = \frac{3\pi r^{3}}{G T^{2} R^{3}}$$$R$ 为中心天体半径
近表面卫星密度$$\rho = \frac{3\pi}{G T^{2}}$$当 $r \approx R$
  • 已知环绕天体的周期和轨道半径可求中心天体质量，但不能求环绕天体本身的质量。
  • 近地卫星的周期可以决定中心天体的密度。
易错提醒｜估质量时必须区分中心天体半径 $R$ 与卫星轨道半径 $r$，不要混用。

4三个宇宙速度

第一宇宙速度是近地卫星的环绕速度，也是最小的发射速度；第二宇宙速度是脱离地球的最小发射速度；第三宇宙速度是脱离太阳系的最小发射速度。

第一宇宙速度$$v_1 = \sqrt{\frac{GM}{R}} = \sqrt{gR} \approx 7.9\,\mathrm{km/s}$$近地环绕速度
第二宇宙速度$$v_2 \approx 11.2\,\mathrm{km/s}$$脱离地球
第三宇宙速度$$v_3 \approx 16.7\,\mathrm{km/s}$$脱离太阳系
  • 第一宇宙速度既是最大的环绕速度，又是最小的发射速度。
  • 发射速度越大则轨道越高，但稳定后的环绕速度反而越小。
易错提醒｜发射速度与环绕速度是不同的概念；轨道越高，环绕速度越小而发射速度越大。

5人造卫星与同步卫星

人造卫星绕地球运动时万有引力提供向心力；地球同步卫星位于赤道上方，其周期等于地球自转周期，相对地面静止。

卫星环绕速度$$v = \sqrt{\frac{GM}{r}}$$轨道越高线速度越小
卫星周期$$T = 2\pi\sqrt{\frac{r^{3}}{GM}}$$轨道越高周期越大
同步卫星高度$$h \approx 3.6\times10^{4}\,\mathrm{km}$$周期恒为 $24\,\mathrm{h}$
  • 同步卫星只能在赤道上空的特定高度，其角速度与地球自转相同。
  • 轨道越高，$v$ 越小、$T$ 越大、向心加速度越小。
易错提醒｜同步卫星不是离地球最近的卫星；近地卫星周期约 $84\,\mathrm{min}$，远小于 $24\,\mathrm{h}$。

6卫星变轨与双星问题

卫星通过点火加速或减速改变轨道实现变轨；双星系统中两颗星绕共同圆心做圆周运动，周期相同。

变轨速度关系$$v_{\text{近}} \geq v_{\text{远}}$$椭圆轨道近地点速率大
双星周期$$T = 2\pi\sqrt{\frac{d^{3}}{G(m_1+m_2)}}$$$d$ 为两星间距
  • 卫星加速后做离心运动进入高轨道，减速则进入低轨道。
  • 双星系统的角速度、周期相同，向心力由彼此间的万有引力提供。
易错提醒｜从低轨到高轨需要加速使机械能增加，但稳定在高轨后速率反而减小。

1.7功、功率与动能定理

掌握功、功率的计算方法，理解动能定理并能求解变力做功与多过程问题。

1功

力对物体做的功等于力与物体在力方向上位移的乘积，是标量；当力与位移夹角为钝角时力做负功。

功的定义$$W = Fs\cos\alpha$$$\alpha$ 为力与位移的夹角
合力功$$W_{\text{合}} = W_1 + W_2 + \cdots$$各力做功的代数和
  • 功是标量，正负只表示力对物体运动起促进还是阻碍作用。
  • 一对作用力和反作用力做功之和不一定为零。
易错提醒｜计算功时位移是对地位移；摩擦力既可能做负功也可能做正功。

2功率

功率是描述做功快慢的物理量，分为平均功率和瞬时功率两种。

平均功率$$\bar{P} = \frac{W}{t}$$对应一段时间
瞬时功率$$P = Fv\cos\alpha$$对应某一时刻
  • 机车以恒定功率启动时做加速度减小的加速运动，最大速度 $v_{\max} = \dfrac{P}{f}$。
  • 瞬时功率与平均功率不可混用。
易错提醒｜求瞬时功率用 $P = Fv$，求平均功率用 $W/t$；恒定功率下牵引力随速度增大而减小。

3动能与动能定理

物体由于运动而具有的能量叫动能；合外力对物体做的功等于物体动能的变化量。

动能$$E_k = \tfrac{1}{2} m v^{2}$$标量，恒不为负
动能定理$$W_{\text{合}} = \Delta E_k = \tfrac{1}{2}mv^{2} - \tfrac{1}{2}mv_0^{2}$$适用于全过程
  • 动能定理不涉及方向，是解决变力做功和多过程问题的重要工具。
  • 动能变化只取决于合外力做的总功，与具体路径无关。
易错提醒｜动能定理中合外力总功包含各力做功的代数和；注意初末动能只与状态有关。

4机车启动问题

机车启动分为恒定功率启动和恒定加速度启动两种情况，前者加速度逐渐减小，后者功率逐渐增大。

恒定功率最大速度$$v_{\max} = \frac{P}{f}$$牵引力等于阻力时
恒定牵引力加速$$F - f = ma$$匀加速阶段
匀加速最大速度$$v_1 = \frac{P}{F}$$恰好达到额定功率时
  • 恒定功率启动先做加速度减小的变加速运动，最后做匀速运动。
  • 恒定加速度启动先匀加速，再变加速，最后匀速。
易错提醒｜两种启动方式的最大速度相同，但达到最大速度的过程和所用时间不同。

5变力做功的求解方法

变力做功可用动能定理、图象法（$F-x$ 图线下面积）、微元法或等效替换等方法求解。

图象法$$W = \overline{F}\,x$$$F-x$ 图线下的面积表示功
动能定理求变力功$$W_{F} = \Delta E_k - W_{\text{其他}}$$间接求解变力做功
  • $F-x$ 图象与横轴围成的面积表示功，面积在横轴下方时功为负。
  • 变力做功常借助动能定理或其他力做功间接求出。
易错提醒｜不能用 $W = Fs$ 直接求变力做功；注意区分恒力做功与变力做功。

1.8机械能守恒定律

理解重力势能、弹性势能与机械能，掌握机械能守恒的条件、表达式与应用。

1重力势能与重力做功

物体由于被举高而具有的能量叫重力势能；重力做功只与始末位置的高度差有关，与路径无关。

重力势能$$E_p = mgh$$相对参考平面，可正可负
重力做功$$W_G = mgh = -\Delta E_p$$与路径无关
  • 重力做正功重力势能减少，重力做负功重力势能增加。
  • 重力势能具有相对性，与参考平面的选取有关，但势能的变化量与参考平面无关。
易错提醒｜重力势能大小与零势能面的选取有关；重力做功与路径无关，但摩擦力做功与路径有关。

2弹性势能

发生弹性形变的物体因各部分间弹力的相互作用而具有的能量叫弹性势能。

弹性势能$$E_p = \tfrac{1}{2} k x^{2}$$与形变量的平方成正比
弹力做功$$W_{\text{弹}} = -\Delta E_p$$与路径无关
  • 弹性势能由劲度系数和形变量共同决定。
  • 弹力做功与重力做功类似，与路径无关。
易错提醒｜弹性势能表达式只在弹性限度内成立；形变量是相对原长的变化量。

3机械能守恒定律

在只有重力或弹力做功的情形下，物体的动能和势能相互转化，机械能的总量保持不变。

机械能$$E = E_k + E_p$$动能与势能之和
守恒表达式$$E_{k1} + E_{p1} = E_{k2} + E_{p2}$$初末状态的机械能相等
另一种形式$$\Delta E_k = -\Delta E_p$$动能增加等于势能减少
  • 机械能守恒的条件是只有重力或弹力做功。
  • 存在摩擦力或其他力做功时机械能不守恒，但总能量仍然守恒。
易错提醒｜有摩擦力做功时机械能不守恒；解题前应先判断是否满足守恒条件。

4功能关系与能量守恒

功是能量转化的量度，不同力做功对应不同形式的能量转化；能量在转化过程中总量保持不变。

动能定理$$W_{\text{合}} = \Delta E_k$$合力功对应动能变化
机械能变化$$W_{\text{其他}} = \Delta E$$除重力、弹力外其他力做功
摩擦生热$$Q = f \Delta s$$$\Delta s$ 为相对滑动路程
  • 除重力、弹力外其他力做的功等于机械能的变化量。
  • 摩擦生热等于摩擦力与相对滑动路程的乘积。
易错提醒｜摩擦生热中的路程是相对滑动路程，不是物体对地的路程。

5机械能守恒的常见模型

光滑轨道上的小球、绳连接的物体、弹簧振子等是机械能守恒的典型模型，需正确选取系统与初末状态。

光滑圆弧最低点$$mgh = \tfrac{1}{2}mv^{2}$$重力势能转化为动能
系统守恒$$\Delta E_{kA} + \Delta E_{kB} = 0$$系统内机械能转移
  • 选取系统时把相互作用的物体和弹簧纳入，可简化能量分析。
  • 轻绳突然绷紧的瞬间可能有机械能损失，需要分段处理。
易错提醒｜绳突然绷直、物体碰撞等情况机械能可能不守恒，要注意过程分段分析。

1.9动量、冲量与动量守恒

理解动量、冲量的概念，掌握动量定理与动量守恒定律，会分析碰撞、反冲与爆炸等问题。

1动量与冲量

物体的质量与速度的乘积叫动量，是矢量；力与作用时间的乘积叫冲量，也是矢量。

动量$$p = mv$$方向与速度方向相同
冲量$$I = Ft$$方向与力的方向相同
动量变化$$\Delta p = mv_2 - mv_1$$矢量差，需规定正方向
  • 动量和冲量都是矢量，运算遵循平行四边形定则。
  • 动量变化量是矢量，其方向由速度变化的方向决定。
易错提醒｜动量和动能不同，动量是矢量、动能是标量；两者满足 $E_k = p^{2}/(2m)$。

2动量定理

物体所受合外力的冲量等于物体动量的变化量。

动量定理$$I_{\text{合}} = \Delta p = mv_2 - mv_1$$矢量式，需规定正方向
平均力$$\bar{F} = \frac{\Delta p}{\Delta t}$$可求缓冲过程中的平均作用力
  • 动量定理可用于求变力作用下的平均力与作用时间。
  • 缓冲可以延长作用时间，从而减小冲击力。
易错提醒｜动量定理是矢量式，解题必须规定正方向；$\Delta p$ 是末动量减初动量。

3动量守恒定律

系统不受外力或所受合外力为零时，系统总动量保持不变；当内力远大于外力时也可近似认为动量守恒。

守恒式$$m_1v_1 + m_2v_2 = m_1v_1' + m_2v_2'$$系统总动量保持不变
守恒条件$$\sum p = \text{常量}$$系统所受合外力为零
  • 动量守恒定律适用于宏观与微观、低速与高速的一切情况。
  • 判断守恒看合外力是否为零；若某方向合外力为零，则该方向动量守恒。
易错提醒｜动量守恒有条件，不能不判断就套用；碰撞、爆炸时内力远大于外力可近似守恒。

4弹性碰撞与完全非弹性碰撞

碰撞过程中动量守恒；动能是否损失取决于碰撞类型，弹性碰撞动能守恒，完全非弹性碰撞动能损失最大。

弹性碰撞$$\tfrac{1}{2}m_1v_1^{2} = \tfrac{1}{2}m_1v_1'^{2} + \tfrac{1}{2}m_2v_2'^{2}$$动能也守恒
完全非弹性$$v_1' = v_2' = \frac{m_1v_1}{m_1+m_2}$$碰后两者共速
等质量弹性碰$$v_1' = 0,\quad v_2' = v_1$$交换速度
  • 碰撞前后动量必然守恒，动能不会增加。
  • 质量相等的两物体发生弹性正碰时交换速度。
易错提醒｜完全非弹性碰撞动能损失最大但动量仍守恒；碰后的速度不能违背物理实际。

5反冲与爆炸

反冲运动是系统在内力作用下分裂且总动量守恒的运动；爆炸过程内力极大、时间极短，动量近似守恒。

反冲守恒$$0 = m_1v_1 + m_2v_2$$初动量为零的系统
爆炸分裂$$m_1v_1 = m_2v_2$$分裂后两部分动量等大反向
  • 反冲运动中系统内部相互作用，总动量守恒。
  • 爆炸过程中机械能增加，但动量守恒。
易错提醒｜反冲和爆炸是动量守恒的典型，但机械能不一定守恒（爆炸时机械能增加）。

6动量与能量结合的综合问题

涉及碰撞、子弹打木块、滑块木板等模型时，常需同时用动量守恒与能量关系（动能定理或能量守恒）求解。

摩擦生热$$Q = f \Delta s = E_{k\text{初}} - E_{k\text{末}}$$与相对路程有关
相对滑动$$\Delta s = s_{\text{相对}}$$相对位移决定热量
  • 动量守恒求速度，能量关系求做功或热量，两者结合解题。
  • 摩擦生热中的相对路程由两物体的相对运动决定。
易错提醒｜子弹打木块问题中系统动量守恒但机械能不守恒，注意区分相对位移与对地位移。

从静电场、恒定电流到磁场、电磁感应与交变电流、电磁波，是高考的又一大支柱，约占全卷 35%。

2.1静电场：库仑定律与电场强度

掌握电荷守恒、库仑定律、电场强度的定义及其叠加，理解电场线的性质。

1电荷守恒与元电荷

电荷既不能被创造也不能被消灭，只能从一个物体转移到另一个物体，此即电荷守恒定律；元电荷是最小的电荷量。

元电荷$$e = 1.6\times10^{-19}\,\mathrm{C}$$所有带电体的电荷量是其整数倍
电荷守恒$$\sum Q_{\text{初}} = \sum Q_{\text{末}}$$孤立系统的电荷总量不变
  • 接触带电是电荷在导体间重新分配，电荷总量守恒。
  • 元电荷是电荷量的最小单位，并不是电子本身。
易错提醒｜元电荷是电荷量而不是电荷；起电方式有摩擦起电、接触起电和感应起电。

2库仑定律

真空中两个静止点电荷之间的相互作用力，与它们电荷量的乘积成正比，与它们之间距离的平方成反比。

库仑定律$$F = k\frac{q_1 q_2}{r^{2}}$$$k = 9\times10^{9}\,\mathrm{N\cdot m^{2}/C^{2}}$
适用条件$$r \gg \text{带电体尺寸}$$点电荷模型
  • 库仑力满足牛顿第三定律，同号电荷相斥、异号电荷相吸。
  • 库仑定律适用于真空中的点电荷。
易错提醒｜库仑定律不能用于任意形状带电体；$r$ 趋于零时公式不再适用。

3电场强度

电场强度是描述电场强弱的物理量，等于单位正电荷在该点所受的电场力，方向与正电荷受力方向相同。

定义式$$E = \frac{F}{q}$$适用于一切电场
点电荷场强$$E = k\frac{Q}{r^{2}}$$由场源电荷决定
匀强电场$$E = \frac{U}{d}$$适用于匀强电场
  • 电场强度由电场本身决定，与试探电荷无关。
  • $E = F/q$ 是定义式，$E = kQ/r^{2}$ 是点电荷场强的决定式。
易错提醒｜电场强度是矢量，其大小与试探电荷的正负、电荷量均无关。

4电场线

电场线是形象描述电场的曲线，其疏密表示场强大小，切线方向表示该点的场强方向；电场线从正电荷出发终止于负电荷。

场强方向$$\vec{E} \parallel \text{电场线切线}$$与正电荷受力方向相同
疏密关系$$\text{疏密} \propto E$$越密处场强越大
  • 电场线不闭合、不相交、不中断。
  • 匀强电场的电场线是间距相等的平行直线。
易错提醒｜电场线不是真实存在的，是假想的曲线；电场线方向与正电荷受力方向相同。

5电场叠加与静电平衡

多个电荷共同产生的电场在某点的场强等于各电荷单独产生的场强的矢量和。导体达到静电平衡时内部场强为零。

场强叠加$$\vec{E} = \vec{E}_1 + \vec{E}_2 + \cdots$$矢量合成
静电平衡$$E_{\text{内}} = 0$$导体内部场强为零
  • 静电平衡时导体是等势体，其表面是等势面。
  • 导体表面场强方向垂直于表面，尖端处电荷密度大。
易错提醒｜场强叠加要用矢量运算，不能简单相加；导体内部场强为零但表面不一定。

2.2电势、电势能与电容

掌握电势、电势差、电势能的概念，理解等势面与电容器的规律及动态分析。

1电势能与电场力做功

电荷在电场中具有的势能叫电势能；电场力做功与路径无关，电场力做正功时电势能减少。

电场力做功$$W = qU$$与路径无关
电势能变化$$W = -\Delta E_p$$电场力做正功电势能减少
  • 电场力做功只与始末位置的电势差有关，与路径无关。
  • 电场力做正功，电势能减少；电场力做负功，电势能增加。
易错提醒｜正负电荷受力方向不同，判断做功与电势能变化要结合电荷的正负。

2电势与电势差

电场中某点的电势等于单位正电荷在该点所具有的电势能；两点间电势之差为电势差，也叫电压。

电势定义$$\varphi = \frac{E_p}{q}$$标量，有正负
电势差$$U_{AB} = \varphi_A - \varphi_B = \frac{W_{AB}}{q}$$等于电场力做功与电荷量之比
匀强电场关系$$U = Ed$$$d$ 为沿场强方向的距离
  • 电势是标量，其正负表示相对零电势的高低。
  • 沿电场线方向电势逐渐降低。
易错提醒｜电势差 $U_{AB} = \varphi_A - \varphi_B$，代入时注意下标顺序；沿电场线方向电势降低。

3等势面

电场中电势相等的各点构成等势面，电场线与等势面处处垂直，电场线由电势高的等势面指向电势低的等势面。

垂直关系$$\vec{E} \perp \text{等势面}$$电场线垂直等势面
等势面间距$$d \propto \frac{1}{E}$$场强越大处等势面越密
  • 沿等势面移动电荷时电场力不做功。
  • 等势面越密的地方电场强度越大。
易错提醒｜电场线与等势面垂直；等势面不能相交。

4电容器与电容

电容器是储存电荷的装置，电容是描述电容器容纳电荷本领的物理量，等于所带电荷量与两极板电压之比。

电容定义$$C = \frac{Q}{U}$$单位法拉 $\mathrm{F}$
平行板电容器$$C = \frac{\varepsilon_r S}{4\pi k d}$$与正对面积、介质、间距有关
板间场强$$E = \frac{U}{d}$$板间为匀强电场
  • 电容由电容器本身的结构决定，与电荷量、电压无关。
  • 平行板电容器 $C$ 与正对面积 $S$ 成正比，与板间距 $d$ 成反比。
易错提醒｜电容 $C$ 与 $Q$、$U$ 无关；改变板间距时要注意是电压不变还是电荷量不变。

5电容器的动态分析

电容器接入电路时电压不变（始终与电源相连），充电后断开电源时电荷量不变，据此分析板间电场的变化。

电压不变$$U = \text{常量} \Rightarrow E = \frac{U}{d}$$连电源：$U$ 不变
电荷量不变$$Q = \text{常量} \Rightarrow E = \frac{4\pi k Q}{\varepsilon_r S}$$断电源：$Q$ 不变
  • 电容器始终接电源时 $U$ 不变；充电后断开电源则 $Q$ 不变。
  • 两种情况下板间场强变化的判断方法不同。
易错提醒｜动态分析务必先判断是 $U$ 不变还是 $Q$ 不变，再选择相应的公式。

2.3带电粒子在电场中的运动

掌握带电粒子在电场中的加速与偏转规律，理解示波管原理与电场中的功能关系。

1带电粒子的加速

带电粒子在加速电场中，电场力做功使其动能增加，可用动能定理求解获得的末速度。

加速动能定理$$qU = \tfrac{1}{2}mv^{2} - \tfrac{1}{2}mv_0^{2}$$电场力做功等于动能增量
加速末速度$$v = \sqrt{\frac{2qU}{m}}$$初速度为零时
  • 常用动能定理处理加速问题，不必考虑中间过程。
  • 若忽略重力，加速效果只与电压和粒子的比荷有关。
易错提醒｜是否考虑重力要视粒子而定，微观粒子一般忽略重力，带电小球则不能忽略。

2带电粒子的偏转

带电粒子垂直进入匀强电场后做类平抛运动，可分解为沿初速度方向的匀速运动和沿电场方向的匀加速运动。

侧移量$$y = \frac{1}{2}at^{2} = \frac{qU L^{2}}{2mdv_0^{2}}$$$L$ 为板长，$d$ 为板间距
偏转角$$\tan\theta = \frac{v_y}{v_0} = \frac{qUL}{mdv_0^{2}}$$出射速度方向
  • 偏转问题用类平抛的分解思想处理，沿初速度方向不受力做匀速运动。
  • 侧移量与偏转电压成正比。
易错提醒｜带电粒子能否穿出电场需先判断，若打在极板上则不能套用偏转公式。

3示波管原理

示波管中电子经加速、偏转后打在荧光屏上，通过控制偏转电压使电子束在屏上扫描并绘出波形。

屏上偏移$$Y = y + L'\tan\theta$$$L'$ 为偏转板到屏的距离
比例关系$$Y \propto U$$偏移与偏转电压成正比
  • 电子在偏转电场中做类平抛运动，出电场后做匀速直线运动。
  • 屏上偏移量与偏转电压成正比。
易错提醒｜出电场后的偏移要加上匀速直线阶段的位移，不能用侧移量直接当作屏上偏移。

4电场中的功能关系

带电体在电场中运动时，电场力做功对应电势能的变化，可结合动能定理或能量守恒分析。

动能定理$$W_{\text{电}} + W_{\text{重}} = \Delta E_k$$各力做功之和等于动能增量
能量守恒$$\Delta E_k + \Delta E_p + \Delta E_{p,\text{电}} = 0$$忽略其他力时
  • 电场力做功对应电势能变化，与重力做功类似。
  • 电场中带电体的机械能不守恒，但总能量守恒。
易错提醒｜有电场力做功时机械能不守恒，需把电势能计入总能量中。

5电场中的平衡与直线运动

带电粒子在电场和重力场共同作用下可以处于平衡或做直线运动，需要正确进行受力分析。

平衡条件$$qE = mg$$电场力与重力平衡
合力大小$$F_{\text{合}} = \sqrt{(qE)^{2} + (mg)^{2}}$$电场力与重力垂直时
  • 带电粒子做直线运动时，合力方向与速度方向共线。
  • 二力平衡时粒子做匀速直线运动或保持静止。
易错提醒｜带电微粒在电场中平衡的问题不能漏掉重力，要注意各力的方向。

2.4恒定电流与电路

掌握欧姆定律、串并联规律、电功电热与闭合电路欧姆定律，会分析电源功率与多用电表。

1电流与欧姆定律

电荷的定向移动形成电流；导体中的电流与两端电压成正比，与导体电阻成反比。

电流定义$$I = \frac{q}{t} = nqvS$$微观表达式
欧姆定律$$I = \frac{U}{R}$$适用于纯电阻电路
电阻定律$$R = \rho\frac{L}{S}$$由材料与几何尺寸决定
  • 电阻由导体本身的性质决定，与电压、电流无关。
  • 电流的微观表达式 $I = nqvS$ 中 $n$ 为单位体积内的自由电荷数。
易错提醒｜电阻定律中 $L$ 是导体长度、$S$ 是横截面积；拉伸导体时长度与横截面积同时变化。

2串联与并联电路

串联电路中电流处处相等，总电阻等于各电阻之和；并联电路中各支路两端电压相等，总电阻的倒数等于各分电阻倒数之和。

串联电阻$$R = R_1 + R_2 + \cdots$$分压与电阻成正比
并联电阻$$\frac{1}{R} = \frac{1}{R_1} + \frac{1}{R_2} + \cdots$$分流与电阻成反比
两电阻并联$$R = \frac{R_1 R_2}{R_1 + R_2}$$常用简化式
  • 串联分压与电阻成正比，并联分流与电阻成反比。
  • 并联后的总电阻小于任一支路的电阻。
易错提醒｜并联电阻公式与串联不同，不要混淆；混联电路需先识别串并联结构。

3电功、电热与电功率

电流做功把电能转化为其他形式的能；电流通过导体产生的热量叫电热，由焦耳定律计算。

电功$$W = UIt$$适用于一切电路
电热$$Q = I^{2}Rt$$焦耳定律
电功率$$P = UI$$纯电阻电路中 $P = I^{2}R = U^{2}/R$
  • 纯电阻电路中电功等于电热；非纯电阻电路中电功大于电热。
  • 电动机、电解槽等属于非纯电阻用电器。
易错提醒｜非纯电阻电路中不能用 $W = I^{2}Rt$ 求电功，要注意区分电功与电热。

4闭合电路欧姆定律

闭合电路中的电流与电源电动势成正比，与内、外电路的总电阻成反比。

闭合电路欧姆定律$$I = \frac{E}{R + r}$$$r$ 为电源内阻
路端电压$$U = E - Ir$$随电流增大而减小
电动势$$E = U_{\text{外}} + U_{\text{内}}$$等于内、外电压之和
  • 路端电压随外电阻减小而减小，随电流增大而减小。
  • 电源的 $U-I$ 图线斜率的绝对值表示电源内阻。
易错提醒｜电动势是电源的属性，与是否接入电路无关；路端电压不等于电动势。

5电源的功率与效率

电源把其他形式的能转化为电能，其总功率等于电动势与电流的乘积，输出功率随外电阻变化。

总功率$$P_{\text{总}} = EI$$电源的总功率
输出功率$$P_{\text{出}} = UI = I^{2}R$$外电路的功率
效率$$\eta = \frac{R}{R+r}$$外电阻越大效率越高
  • 当外电阻等于内阻时，电源的输出功率最大。
  • 效率随外电阻增大而提高，与输出功率最大并不一致。
易错提醒｜输出功率最大（$R = r$）时电源效率只有 $50\%$，不要混淆功率最大与效率最高。

6多用电表与伏安法测电阻

多用电表可以测量电压、电流和电阻；用伏安法测电阻时，应依据待测电阻的大小选择安培计内接或外接。

欧姆表测电阻$$R_x = \frac{E}{I} - R_{\text{内}}$$表头电流对应阻值
内接法误差$$R_{\text{测}} = R_x + R_A$$适合测大电阻
外接法误差$$R_{\text{测}} = \frac{R_x R_V}{R_x + R_V}$$适合测小电阻
  • 大电阻用安培计内接、小电阻用外接，可减小系统误差。
  • 欧姆表换挡后需要重新进行欧姆调零。
易错提醒｜欧姆表刻度不均匀且最右端为零；测电阻时不能用手同时接触两表笔的金属部分。

2.5磁场、安培力与洛伦兹力

掌握磁感应强度、磁感线与安培定则，理解安培力、洛伦兹力及速度选择器。

1磁感应强度与磁感线

磁感应强度是描述磁场强弱的物理量，方向即小磁针静止时北极的指向；磁感线在磁体外部由 $N$ 极指向 $S$ 极。

磁感应强度定义$$B = \frac{F}{IL}$$电流元垂直于磁场时
单位$$1\,\mathrm{T} = 1\,\mathrm{N/(A\cdot m)}$$特斯拉
  • 磁感应强度是矢量，其方向是小磁针北极所受磁场力的方向。
  • 磁感线是闭合曲线，磁体外部由 $N$ 极到 $S$ 极，内部由 $S$ 极到 $N$ 极。
易错提醒｜磁感线是闭合曲线，不中断也不相交；磁场中某点的 $B$ 与电流元无关。

2安培定则与磁场的叠加

用右手螺旋定则（安培定则）判断直线电流、环形电流和通电螺线管产生的磁场方向；多个电流产生的磁场可用矢量叠加。

直线电流磁场$$B = \frac{\mu_0 I}{2\pi r}$$距导线 $r$ 处
匀强磁场$$B = \text{常量}$$通电螺线管内部近似匀强
  • 安培定则用于判断电流产生磁场的方向。
  • 磁感应强度的叠加遵循矢量合成法则。
易错提醒｜安培定则（右手螺旋）与判断安培力的左手定则用途不同，不可混用。

3安培力

通电导线在磁场中受到的作用力叫安培力，方向由左手定则判定，大小与电流、磁感应强度和有效长度有关。

安培力$$F = BIL\sin\theta$$$\theta$ 为 $I$ 与 $B$ 的夹角
垂直情形$$F = BIL$$导线与磁场垂直
  • 安培力方向总是垂直于 $B$ 与 $I$ 决定的平面，由左手定则判定。
  • 当导线平行于磁场方向时不受安培力。
易错提醒｜安培力公式中 $L$ 是有效长度，弯曲导线取两端点连线的长度。

4洛伦兹力

运动电荷在磁场中受到的作用力叫洛伦兹力，方向由左手定则判定，其方向垂直于速度与磁场决定的平面。

洛伦兹力$$F = qvB\sin\theta$$$\theta$ 为 $v$ 与 $B$ 的夹角
垂直情形$$F = qvB$$速度垂直于磁场
  • 洛伦兹力方向与速度垂直，只改变速度方向，不做功。
  • 洛伦兹力是安培力的微观本质。
易错提醒｜洛伦兹力永远不做功；应用左手定则时要注意电荷的正负。

5速度选择器与磁流体

速度选择器中电场力与洛伦兹力平衡，只有特定速度的粒子才能沿直线通过。

速度选择器$$qE = qvB$$电场力与洛伦兹力平衡
通过速度$$v = \frac{E}{B}$$与电荷量、质量无关
  • 速度选择器只选择速度，与粒子的电荷量、质量无关。
  • 只有电场力与洛伦兹力方向相反时才能平衡。
易错提醒｜速度选择器中改变电场或磁场的方向会改变所选择的速度方向。

2.6带电粒子在磁场中的运动

掌握带电粒子在匀强磁场中做匀速圆周运动的规律，会处理有界磁场、复合场与质谱仪问题。

1匀速圆周运动规律

带电粒子垂直射入匀强磁场时，洛伦兹力提供向心力，粒子做匀速圆周运动。

半径公式$$r = \frac{mv}{qB}$$由洛伦兹力提供向心力
周期公式$$T = \frac{2\pi m}{qB}$$与速率无关
  • 圆周运动的周期与速率无关，只由比荷和磁感应强度决定。
  • 洛伦兹力提供向心力，粒子的速率保持不变。
易错提醒｜半径与速度成正比，周期与速度无关，要注意二者区别。

2圆周运动的确定方法

确定圆心、半径和圆心角是解题关键：圆心在洛伦兹力的方向上，可用几何关系或弦的垂直平分线确定。

半径与弦$$r = \frac{d}{2\sin\theta}$$$d$ 为弦长，$\theta$ 为弦切角
运动时间$$t = \frac{\varphi}{2\pi}T$$$\varphi$ 为圆心角
  • 找圆心的常用方法：洛伦兹力指向圆心，或弦的垂直平分线过圆心。
  • 粒子在磁场中运动的时间由圆心角决定。
易错提醒｜求时间要用圆心角而不是弦切角；圆心角等于弦切角的两倍。

3有界磁场中的临界与极值问题

带电粒子在有界磁场中运动时，恰好穿出、恰好不穿出等临界情形往往对应轨迹与边界相切。

临界半径$$r = \frac{d}{1 - \cos\theta}$$轨迹与边界相切
几何关系$$R = \frac{L}{\sin\theta}$$$L$ 为边界长度
  • 临界情况常对应轨迹与磁场边界相切。
  • 利用几何关系建立半径与已知长度之间的联系。
易错提醒｜临界问题要注意粒子可能的运动方向，画图分析轨迹是关键。

4带电粒子在复合场中的运动

带电粒子在电场、磁场和重力场中运动时，需综合考虑各力，常见匀速直线运动、匀速圆周运动和复杂的曲线运动。

二力平衡$$qE = qvB$$电场力与洛伦兹力平衡
重力与洛伦兹力$$mg = qvB$$重力场与磁场中平衡
  • 三力平衡时粒子做匀速直线运动。
  • 只有洛伦兹力提供向心力时粒子做匀速圆周运动。
易错提醒｜复合场中要注意各力的方向与做功情况，洛伦兹力不做功。

5质谱仪与回旋加速器

质谱仪利用加速和偏转来测定粒子的比荷；回旋加速器利用磁场使粒子做圆周运动、用电场加速，可在较小空间内获得高能粒子。

质谱仪半径$$r = \frac{1}{B}\sqrt{\frac{2mU}{q}}$$由加速与偏转联立
回旋最大动能$$E_k = \frac{q^{2}B^{2}R^{2}}{2m}$$$R$ 为最大半径
  • 质谱仪中比荷不同的粒子偏转半径不同，可分离同位素。
  • 回旋加速器的最大动能由磁场和半径决定，与加速电压无关。
易错提醒｜回旋加速器加速次数与电压有关，但最终动能只由 $B$ 和 $R$ 决定。

2.7电磁感应

掌握法拉第电磁感应定律、楞次定律，理解自感、涡流及电磁感应中的电路、力学与能量问题。

1磁通量与电磁感应现象

磁通量表示穿过某一面积的磁感线条数；当穿过闭合回路的磁通量发生变化时，回路中就会产生感应电流。

磁通量$$\Phi = BS\cos\theta$$$\theta$ 为 $B$ 与面法线的夹角
磁通量变化$$\Delta\Phi = \Phi_2 - \Phi_1$$变化才会产生感应电流
  • 产生感应电流的条件是穿过闭合回路的磁通量发生变化。
  • 磁通量是标量但有正负，需注意面的法线方向。
易错提醒｜磁通量变化有三种方式：$B$ 变、$S$ 变、夹角变；只有磁通量变化才产生感应电流。

2法拉第电磁感应定律

回路中感应电动势的大小与穿过回路的磁通量的变化率成正比。

法拉第定律$$E = n\frac{\Delta\Phi}{\Delta t}$$$n$ 为线圈匝数
切割公式$$E = BLv\sin\theta$$导线切割磁感线
旋转切割$$E = \tfrac{1}{2}BL^{2}\omega$$绕一端转动的导体棒
  • 感应电动势与磁通量的变化率成正比，与磁通量本身的大小无关。
  • 导体棒切割磁感线产生电动势，$v$、$B$、$L$ 两两垂直时 $E = BLv$。
易错提醒｜磁通量大不代表电动势大，关键看变化率；$n$ 匝线圈的电动势是单匝的 $n$ 倍。

3楞次定律

感应电流的磁场总要阻碍引起感应电流的磁通量的变化，即「增反减同」。

楞次定律$$\Delta\Phi \uparrow \Rightarrow B_{\text{感}} \text{反向}$$阻碍磁通量的变化
推广表述$$\text{感应电流阻碍相对运动}$$来拒去留
  • 楞次定律的本质是能量守恒，感应电流的磁场阻碍磁通量的变化。
  • 可用「增反减同」「来拒去留」快速判断。
易错提醒｜楞次定律中的「阻碍」不是「阻止」，磁通量仍在变化，只是变化被减缓。

4自感与涡流

导体自身电流变化引起磁通量变化而产生感应电动势叫自感；变化的磁场在导体中产生涡流。

自感电动势$$E = L\frac{\Delta I}{\Delta t}$$$L$ 为自感系数
自感系数单位$$1\,\mathrm{H} = 1\,\mathrm{Wb/A}$$亨利
  • 自感电动势总阻碍自身电流的变化，通电时延缓和断电时延续电流。
  • 涡流既可以被利用（如电磁炉），也可能有害（发热损耗）。
易错提醒｜断电瞬间线圈可能产生很高的自感电动势，注意「亮一下再熄灭」的现象。

5电磁感应中的电路与力学问题

电磁感应中的导体棒问题常结合电路和力学分析：感应电动势充当电源，安培力往往阻碍相对运动。

感应电流$$I = \frac{BLv}{R + r}$$由闭合电路欧姆定律求得
安培力$$F = \frac{B^{2}L^{2}v}{R + r}$$阻碍相对运动
收尾速度$$v = \frac{FR}{B^{2}L^{2}}$$外力与安培力平衡时
  • 导体棒切割磁感线时充当电源，安培力方向与相对运动方向相反。
  • 恒定外力作用下导体棒最终达到匀速，此时合力为零。
易错提醒｜分析导体棒问题要同时考虑电磁感应与牛顿定律、能量关系，注意回路总电阻。

6电磁感应中的能量转化

电磁感应过程伴随着能量转化，外力克服安培力做的功等于回路中产生的电能（焦耳热）。

能量守恒$$W_{\text{外}} = Q$$克服安培力做功等于电热
电热$$Q = I^{2}Rt$$由焦耳定律计算
  • 克服安培力做的功等于电路中产生的总电热。
  • 电磁感应能量问题常结合动能定理或能量守恒求解。
易错提醒｜回路产生的电能来自其他形式能的转化，要注意区分机械能与电能的关系。

2.8交变电流、变压器与远距离输电

掌握正弦交变电流的产生与描述，理解变压器原理、远距离输电以及电感电容对交流的作用。

1正弦交变电流的产生

线圈在匀强磁场中绕垂直于磁场的轴匀速转动，会产生按正弦规律变化的交变电动势。

峰值$$E_m = nBS\omega$$转轴垂直于磁场
瞬时值$$e = E_m\sin\omega t$$从中性面开始计时
有效值$$E = \frac{E_m}{\sqrt{2}}$$适用于正弦交流电
  • 线圈位于中性面时磁通量最大而电动势为零，每经过中性面电流方向改变一次。
  • 正弦交流电的有效值等于峰值的 $1/\sqrt{2}$。
易错提醒｜有效值用于计算功、热与功率，峰值用于判断耐压；非正弦交流电的有效值需由定义计算。

2描述交变电流的物理量

描述交变电流的物理量有周期、频率、峰值和有效值；照明电路中的 $220\,\mathrm{V}$ 指有效值。

周期与频率$$T = \frac{1}{f} = \frac{2\pi}{\omega}$$角速度 $\omega = 2\pi f$
有效值定义$$Q = I^{2}RT$$按热效应等效定义
  • 交流电表的读数、用电器铭牌参数均指有效值。
  • 非正弦交流电的有效值需从热效应等效的角度定义和计算。
易错提醒｜电容器的耐压值应按峰值考虑；计算发热、功率要用有效值。

3变压器原理

变压器利用互感现象改变交流电压，理想变压器原、副线圈的电压比等于匝数比，输入功率等于输出功率。

电压比$$\frac{U_1}{U_2} = \frac{n_1}{n_2}$$与匝数成正比
电流比$$\frac{I_1}{I_2} = \frac{n_2}{n_1}$$只有一个副线圈时
功率关系$$P_1 = P_2$$理想变压器无损耗
  • 理想变压器电压比、电流比与匝数比的关系，功率不变。
  • 副线圈电压由原线圈电压和匝数比决定，与负载无关。
易错提醒｜变压器不能改变直流电压；电流比公式在多副线圈时不适用，应改用功率关系。

4远距离输电

远距离输电通过高压减小输电线上的电流，从而减小线路损耗。

线路损耗$$P_{\text{损}} = I^{2}R_{\text{线}}$$电流越小损耗越小
输电功率$$P = UI$$升压后电流减小
电压损失$$\Delta U = IR_{\text{线}}$$输电线上的电压损失
  • 远距离输电采用高压、小电流以减少线路损耗。
  • 输送功率一定时，输电线电流与输电电压成反比。
易错提醒｜升压之后线路电流减小，用户端再用降压变压器；计算损耗应用输电线电流而非用户电流。

5电感、电容对交流电的作用

电感对交流有阻碍作用，且频率越高阻碍越大；电容能通交流、隔直流，频率越高阻碍越小。

感抗$$X_L = 2\pi f L$$频率越高阻碍越大
容抗$$X_C = \frac{1}{2\pi f C}$$频率越高阻碍越小
  • 电感通直流、阻交流，通低频、阻高频。
  • 电容隔直流、通交流，通高频、阻低频。
易错提醒｜电感与电容对交流的阻碍作用规律相反，注意频率变化时的影响。

2.9电磁波与传感器

了解电磁波的产生、传播与电磁波谱，认识常见传感器的工作原理与应用。

1电磁波的产生与传播

变化的电场产生磁场，变化的磁场产生电场，交替变化的电磁场由近及远传播形成电磁波。

波速关系$$c = \lambda f$$真空中 $c = 3\times10^{8}\,\mathrm{m/s}$
光子能量$$E = h\nu$$电磁波的能量是量子化的
  • 电磁波可以在真空中传播，不需要介质。
  • 真空中所有电磁波的传播速度都等于光速。
易错提醒｜电磁波是横波，其传播不需要介质，这与机械波不同。

2麦克斯韦电磁场理论

麦克斯韦提出变化的磁场产生电场、变化的电场产生磁场，并预言了电磁波的存在。

变化磁场生电$$\frac{\Delta B}{\Delta t} \Rightarrow E$$产生感应电场
理论预言$$c = \frac{1}{\sqrt{\varepsilon_0\mu_0}}$$与光速一致
  • 均匀变化的电场（磁场）产生稳定的磁场（电场）。
  • 周期性变化的电磁场向外传播形成电磁波。
易错提醒｜均匀变化的场产生恒定的场，只有周期性变化才能产生电磁波。

3电磁波谱

按波长（频率）顺序排列的电磁波谱包括无线电波、红外线、可见光、紫外线、$X$ 射线和 $\gamma$ 射线。

波速关系$$c = \lambda\nu$$真空中传播速度相同
光子能量$$E = h\nu$$频率越高能量越大
  • 电磁波谱按频率由低到高：无线电波、红外线、可见光、紫外线、$X$ 射线、$\gamma$ 射线。
  • 频率越高波长越短，粒子性越显著。
易错提醒｜波长与频率成反比；不同波段的电磁波性质不同，用途也不同。

4传感器

传感器是把非电学量（如温度、力、光、声）转换为电学量的器件，便于测量和控制。

热敏电阻$$\frac{\Delta R}{\Delta T}$$温度变化引起阻值变化
光敏电阻$$R \propto \frac{1}{\text{光照强度}}$$光照增强阻值减小
  • 热敏电阻、光敏电阻、霍尔元件是常见的敏感元件。
  • 传感器将非电学量转换为电学量以便进行自动控制。
易错提醒｜正温度系数与负温度系数热敏电阻的阻值变化方向相反，要加以区分。

5电磁波的应用与防护

无线电波用于通信，微波用于雷达和加热，红外线用于遥感和遥控，紫外线用于杀菌，$X$ 射线与 $\gamma$ 射线用于医学和探测。

雷达测距$$d = \frac{ct}{2}$$利用电磁波往返
微波加热$$\text{分子高频振动生热}$$水分子吸收微波
  • 不同波段的电磁波因其特性而有不同的应用。
  • 过强的电磁辐射对人体有害，需要注意防护。
易错提醒｜$X$ 射线和 $\gamma$ 射线电离能力强、穿透能力强，防护要求高。

3 节

分子动理论、固体液体气体的性质与热力学定律，是选考重要内容，注重微观解释与宏观规律的联系。

3.1分子动理论与内能

掌握分子动理论的基本内容，学会用阿伏加德罗常数估算分子大小与数目，理解分子力与内能。

1物体由大量分子组成

物质由大量分子（原子）组成，分子之间存在空隙，分子的直径数量级约为 $10^{-10}\,\mathrm{m}$。

分子数目$$N = nN_A = \frac{m}{M}N_A$$$N_A = 6.02\times10^{23}\,\mathrm{mol^{-1}}$
分子体积$$V_0 = \frac{V_{\text{mol}}}{N_A}$$用于估算分子体积
分子直径$$d = \sqrt[3]{\frac{6V_0}{\pi}}$$按球模型估算
  • 阿伏加德罗常数是联系宏观量与微观量的桥梁。
  • 分子直径的数量级为 $10^{-10}\,\mathrm{m}$。
易错提醒｜用 $V_0 = V_{\text{mol}}/N_A$ 估算的是固体、液体的分子体积，气体分子的间距远大于分子直径。

2分子的热运动与布朗运动

分子永不停息地做无规则运动，温度越高运动越剧烈；布朗运动是悬浮微粒的无规则运动，反映了液体分子的无规则运动。

温度与热运动$$T \uparrow \Rightarrow \text{运动加剧}$$分子平均动能增大
  • 布朗运动不是分子运动，而是悬浮微粒的运动，它间接反映了分子的无规则运动。
  • 布朗运动随温度升高而加剧，随颗粒减小而更明显。
易错提醒｜布朗运动是微粒的运动，需用显微镜才能观察；它说明分子在永不停息地运动。

3分子间作用力

分子之间同时存在引力和斥力，其合力即分子力，随分子间距变化；当分子间距为 $r_0$ 时分子力为零。

分子力$$F = F_{\text{引}} - F_{\text{斥}}$$引力与斥力同时存在
分子势能$$r = r_0 \Rightarrow E_p \text{ 最小}$$平衡位置处势能最小
  • 分子间距 $r = r_0$（约 $10^{-10}\,\mathrm{m}$）时分子力为零，分子势能最小。
  • 分子间距大于 $r_0$ 时表现为引力，小于 $r_0$ 时表现为斥力。
易错提醒｜分子力随间距变化的规律与弹簧不同，引力和斥力同时随间距增大而减小。

4温度与分子平均动能

温度是分子平均动能的标志，温度越高，分子热运动越剧烈，分子的平均动能越大。

分子平均动能$$\bar{E}_k \propto T$$与热力学温度成正比
热力学温度$$T = t + 273.15\,\mathrm{K}$$与摄氏温度的换算
  • 温度是分子平均动能的标志，与单个分子的动能无关。
  • 热力学温度与摄氏温度的换算关系为 $T = t + 273\,\mathrm{K}$（近似）。
易错提醒｜温度相同的不同物质分子平均动能相同，但分子平均速率不同，因为它们质量不同。

5内能

物体内所有分子的动能与分子势能的总和叫内能；内能与温度、体积和物质的量都有关。

内能$$U = E_{k,\text{总}} + E_{p,\text{总}}$$分子动能与势能之和
理想气体内能$$U = f(T)$$只与温度有关
  • 理想气体的内能只与温度有关，与体积无关。
  • 内能是状态量，与温度、体积、物质的量都有关。
易错提醒｜内能与机械能不同；理想气体的内能表达式不含体积，温度不变时内能不变。

3.2固体、液体与气体

了解固体与液体的性质，掌握气体实验三定律、理想气体状态方程与气体压强的微观解释。

1固体与液体的性质

固体分为晶体和非晶体，晶体有确定的熔点且单晶体物理性质可以表现为各向异性；液体具有表面张力。

表面张力$$f = \sigma L$$$\sigma$ 为表面张力系数
晶体特征$$\text{有固定熔点}$$非晶体无固定熔点
  • 单晶体具有各向异性，多晶体和非晶体表现为各向同性。
  • 液体表面张力使液面收缩，液滴趋于球形。
易错提醒｜晶体与非晶体的本质区别是内部分子排列是否规则，而不是外观。

2气体状态参量与气体实验定律

一定质量的气体，其状态由压强、体积、温度共同描述；在温度不变、体积不变或压强不变时，分别满足玻意耳定律、查理定律和盖—吕萨克定律。

玻意耳定律（等温）$$p_1V_1 = p_2V_2$$温度不变
查理定律（等容）$$\frac{p_1}{T_1} = \frac{p_2}{T_2}$$体积不变
盖—吕萨克定律（等压）$$\frac{V_1}{T_1} = \frac{V_2}{T_2}$$压强不变
  • 三个实验定律都以「一定质量的气体」为前提。
  • 等温线在 $p-V$ 图上是双曲线，等容线与等压线在相应坐标系中是过原点的直线。
易错提醒｜气体实验定律必须使用热力学温度；用摄氏温度代入会出错。

3理想气体状态方程

一定质量的理想气体，其压强与体积的乘积与热力学温度成正比。

状态方程$$\frac{pV}{T} = C$$一定质量的气体
两点式$$\frac{p_1V_1}{T_1} = \frac{p_2V_2}{T_2}$$状态变化过程
  • 理想气体状态方程把三个实验定律统一起来，使用热力学温度。
  • 气体压强由分子的平均动能和分子数密度共同决定。
易错提醒｜使用状态方程必须用热力学温度；气体的物质的量或质量变化时不能直接套用。

4气体压强的微观解释

气体的压强是大量分子频繁碰撞器壁产生的，其大小由分子平均动能和分子数密度决定。

气体压强$$p \propto n\bar{E}_k$$$n$ 为分子数密度
分子数密度$$n = \frac{N}{V}$$单位体积内的分子数
  • 温度升高或压缩气体都会使压强增大。
  • 压强的微观本质是大量分子对器壁的碰撞。
易错提醒｜压强增大可能来自分子平均动能增大，也可能来自分子数密度增大，要具体分析。

5气体状态变化的图象

$p-V$、$p-T$、$V-T$ 图象可以直观描述气体的状态变化，图象上的点表示状态，线表示过程。

等温线$$pV = C$$$p-V$ 图为双曲线
等容线$$\frac{p}{T} = C$$$p-T$ 图为过原点的直线
等压线$$\frac{V}{T} = C$$$V-T$ 图为过原点的直线
  • $p-V$ 图中图线下方的面积与做功有关。
  • $p-T$、$V-T$ 图中过原点的直线分别表示等容、等压过程。
易错提醒｜图象坐标轴的原点是热力学温度零点，注意摄氏温度与热力学温度的换算。

3.3热力学定律

掌握热力学第一定律与第二定律，理解能量守恒定律与熵增原理。

1热力学第一定律

改变内能的两种方式是做功和热传递；内能的变化量等于外界对物体做的功与物体吸收的热量之和。

热力学第一定律$$\Delta U = Q + W$$$W$ 为外界对系统做的功
绝热过程$$\Delta U = W$$绝热时 $Q = 0$
  • 做功和热传递在改变内能上是等效的。
  • $\Delta U$、$Q$、$W$ 各量的正负号需按规定统一。
易错提醒｜公式 $\Delta U = Q + W$ 中 $W$ 是外界对系统做的功；若用系统对外做功 $W'$，则为 $\Delta U = Q - W'$。

2热力学第二定律

热量不能自发地从低温物体传到高温物体；另一种表述为：不可能从单一热源吸热并把它全部用来做功而不引起其他变化。

克劳修斯表述$$Q_{\text{低温}} \to Q_{\text{高温}}$$不能自发进行
开尔文表述$$\eta \neq 100\%$$热机效率小于百分之百
  • 热力学第二定律揭示了宏观过程的方向性（不可逆性）。
  • 第二类永动机（效率 $100\%$）不可能实现。
易错提醒｜热量不能自发地从低温传到高温，但可以借助外界做功（如冰箱）实现；第二类永动机不违反能量守恒但违反热力学第二定律。

3能量守恒定律

能量既不会凭空产生，也不会凭空消失，只会从一种形式转化为另一种形式，或从一个物体转移到另一个物体，总量保持不变。

能量守恒$$\Delta E_{\text{总}} = 0$$总能量保持不变
第一类永动机$$\text{不可能}$$违反能量守恒定律
  • 能量守恒定律是自然界最普遍的规律之一。
  • 第一类永动机因违反能量守恒定律而无法实现。
易错提醒｜第一类永动机违反能量守恒，第二类永动机违反热力学第二定律，要加以区分。

4热力学第二定律的熵表述

一切自发过程总是向着无序程度增大（熵增大）的方向进行。

熵增原理$$\Delta S \geq 0$$孤立系统中的自发过程
  • 孤立系统中的自发过程总是朝熵增的方向进行。
  • 在开放系统中可以通过外界做功使系统由无序变为有序。
易错提醒｜熵增原理针对孤立系统；在开放系统中可以出现熵减少的情形（如生命现象）。

5热机与效率

热机是把内能转化为机械能的装置，其效率等于有用功与吸收热量的比值，总小于百分之百。

热机效率$$\eta = \frac{W}{Q_1} = 1 - \frac{Q_2}{Q_1}$$$Q_1$ 为吸收的热量
卡诺效率$$\eta = 1 - \frac{T_2}{T_1}$$理想热机的效率
  • 任何热机的效率都小于百分之百，因为总有部分热量排给低温热源。
  • 提高热机效率可增大高温热源温度或降低低温热源温度。
易错提醒｜热机效率不可能达到百分之百；卡诺效率是理想极限，实际热机效率更低。

🔬 光学

2 节

几何光学与光的波动性两大板块，重点掌握折射定律、全反射、双缝干涉与薄膜干涉。

4.1几何光学：折射与全反射

掌握光的反射、折射定律、折射率、全反射与临界角，理解光的色散与视深现象。

1光的反射与平面镜成像

光在两种介质的分界面处发生反射，反射角等于入射角；平面镜成等大、正立的虚像，像与物关于镜面对称。

反射定律$$\theta_i = \theta_r$$入射角等于反射角
平面镜成像$$s' = s$$像距等于物距
  • 光路可逆是几何光学的普遍规律。
  • 平面镜成等大正立的虚像，像距等于物距。
易错提醒｜平面镜成像为虚像，不能用光屏承接；像与物关于镜面对称。

2光的折射定律与折射率

光从一种介质斜射入另一种介质时传播方向改变，入射角的正弦与折射角的正弦之比等于两种介质的相对折射率。

折射定律$$n_{12} = \frac{\sin\theta_1}{\sin\theta_2}$$斯涅耳定律
折射率定义$$n = \frac{c}{v}$$光在介质中的传播速度
折射定律推广$$n_1\sin\theta_1 = n_2\sin\theta_2$$与介质顺序无关
  • 折射率 $n$ 是介质的光学属性，满足 $n = c/v$。
  • 光从光疏介质射入光密介质时折射角小于入射角。
易错提醒｜折射率 $n = c/v$ 中 $c$ 是真空中光速，$n$ 恒大于 $1$；不要颠倒分子分母。

3全反射与临界角

光从光密介质射向光疏介质时，若入射角增大到某一角度，折射光完全消失、只剩反射光，这种现象叫全反射，对应的入射角叫临界角。

临界角$$\sin C = \frac{1}{n}$$光密介质射向光疏介质
全反射条件$$\theta \geq C$$入射角不小于临界角
  • 发生全反射的两个条件：由光密介质射向光疏介质、入射角不小于临界角。
  • 光导纤维利用全反射来传播光信号。
易错提醒｜全反射必须从光密介质射向光疏介质，从光疏介质射入光密介质不可能发生全反射。

4光的色散

白光经过三棱镜后分解为不同颜色的光带叫色散，说明不同颜色的光在同一介质中折射率不同。

折射率顺序$$n_{\text{紫}} \geq n_{\text{红}}$$紫光折射率最大
速度关系$$v_{\text{紫}} \leq v_{\text{红}}$$介质中紫光最慢
  • 频率越高（紫光）折射率越大、偏折越明显，介质中传播速度越小。
  • 红光的波长最长、折射率最小、临界角最大。
易错提醒｜色散中紫光偏折最大而红光最小；频率、波长、折射率三者的变化关系要理清。

5视深与视高

由于折射，观察到的物体位置与真实位置不同，从而产生视深、视高现象。

视深$$h' = \frac{h}{n}$$$h$ 为实际深度
视高$$h' = nh$$$h$ 为物体到界面的距离
  • 从空气看水中的物体时，视深小于实际深度。
  • 折射现象中的视线方向决定了视深公式的形式。
易错提醒｜视深公式仅适用于垂直观察；斜视时需要按折射定律作图分析。

4.2光的波动性：干涉、衍射与偏振

理解光的干涉、衍射与偏振现象，掌握双缝干涉与薄膜干涉的规律。

1光的干涉

频率相同、相位差恒定的两列光波叠加，某些区域加强、某些区域减弱，形成稳定的明暗相间条纹，即光的干涉。

加强条件$$\Delta d = k\lambda$$出现亮纹
减弱条件$$\Delta d = (2k+1)\frac{\lambda}{2}$$出现暗纹
  • 产生干涉的条件是光的频率相同、相位差恒定。
  • 干涉现象说明光具有波动性。
易错提醒｜不是任何两束光都能发生干涉，必须满足相干条件（频率相同且相位差恒定）。

2双缝干涉

单色光经双缝产生相干光，在屏上形成明暗相间的等间距条纹，条纹间距与波长和缝屏距离有关。

条纹间距$$\Delta y = \frac{L}{d}\lambda$$$L$ 为缝屏距离，$d$ 为缝间距
明纹位置$$y_k = k\frac{L}{d}\lambda$$第 $k$ 级明纹
  • 条纹间距与波长成正比、与缝屏距离成正比、与双缝间距成反比。
  • 白光干涉时中央为白色亮纹，两侧为彩色条纹。
易错提醒｜红光的条纹间距大于紫光；双缝间距越小、屏幕越远，条纹越宽。

3薄膜干涉

光照射在薄膜上，前后表面反射的两列光波叠加产生干涉，形成彩色条纹。

加强条件$$2d = k\lambda$$厚度与波长关系
减弱条件$$2d = (2k+1)\frac{\lambda}{2}$$反射光减弱
  • 肥皂膜、油膜呈现彩色条纹属于薄膜干涉。
  • 检查平面平整度时利用薄膜干涉，条纹弯曲反映表面不平。
易错提醒｜薄膜干涉中要计入前表面反射时的半波损失，相应的加强、减弱条件会改变。

4光的衍射

光绕过障碍物或通过小孔后偏离直线传播的现象叫衍射，单缝衍射中央条纹最亮最宽。

明显衍射条件$$a \leq \lambda$$障碍物尺寸与波长相当
中央条纹$$\text{最亮最宽}$$单缝衍射的特征
  • 发生明显衍射的条件是障碍物或缝的尺寸与波长相当或更小。
  • 单缝衍射的中央亮纹最宽最亮，条纹不等间距。
易错提醒｜干涉与衍射往往同时存在；单缝衍射条纹不等间距，双缝干涉条纹等间距。

5光的偏振

光波是横波，自然光通过偏振片后变为偏振光，这说明光具有偏振特性。

马吕斯定律$$I = I_0\cos^{2}\theta$$$\theta$ 为偏振方向夹角
偏振与传播$$\vec{E} \perp \text{传播方向}$$说明光是横波
  • 光的偏振现象证明光是横波。
  • 自然光通过偏振片后成为偏振光，透射光强减弱。
易错提醒｜偏振现象说明光是横波，声波等纵波没有偏振现象。

⚛️ 近代物理

4 节

波粒二象性与光电效应、原子结构与能级、原子核与核反应、相对论简介，是选考的高频考点。

5.1波粒二象性与光电效应

掌握黑体辐射与能量量子化、光电效应规律、光电效应方程与光子说，理解光的波粒二象性。

1黑体辐射与能量量子化

普朗克提出能量量子化假说，认为能量不能连续变化，只能取分立的数值，从而成功解释了黑体辐射的规律。

能量量子$$E = h\nu$$$h = 6.63\times10^{-34}\,\mathrm{J\cdot s}$
光子能量$$E = \frac{hc}{\lambda}$$与波长的关系
  • 能量量子化是量子力学的基础假设。
  • 普朗克常量 $h$ 是能量量子化的重要标志。
易错提醒｜经典电磁理论无法解释黑体辐射，能量量子化是普朗克的重大突破。

2光电效应现象与规律

光照射金属表面时，金属中的电子吸收光子后逸出形成光电子，此现象叫光电效应；它存在截止频率、饱和光电流和遏止电压。

截止频率$$\nu_c = \frac{W_0}{h}$$小于此频率不发生光电效应
遏止电压$$eU_c = E_{k\max}$$使光电流恰好为零
  • 是否发生光电效应只取决于入射光的频率，与光强无关。
  • 光电子的最大初动能只与入射光频率有关，与光强无关。
易错提醒｜只要频率低于截止频率，无论光强多大都不发生光电效应；光强只影响光电流的大小。

3光电效应方程与光子说

爱因斯坦提出光子说，认为光是一份份不连续的光子；电子吸收光子后，其最大初动能等于光子能量减去逸出功。

光电效应方程$$E_{k\max} = h\nu - W_0$$爱因斯坦光电效应方程
逸出功$$W_0 = h\nu_c$$与金属材料有关
最大初动能$$E_{k\max} = eU_c$$由遏止电压测定
  • 光电效应方程把光子能量、逸出功和光电子最大初动能联系起来。
  • 不同金属的逸出功不同，同一金属的逸出功是定值。
易错提醒｜光电子最大初动能由方程决定，与光强无关；逸出功只与金属材料有关。

4光电效应的图象

通过 $E_k-\nu$ 图象可以分析光电效应规律，图象的截距与斜率都有明确的物理意义。

图象斜率$$k = h$$$E_k - \nu$ 图线的斜率
图象截距$$\nu_c = \frac{W_0}{h}$$横轴截距为截止频率
  • $E_k-\nu$ 图线的斜率等于普朗克常量，横轴截距为截止频率。
  • 光电子的最大初动能与入射光频率成一次函数关系。
易错提醒｜$E_k-\nu$ 图线与纵轴的交点对应的能量为逸出功的相反数，注意符号。

5光的波粒二象性

光既具有波动性又具有粒子性，即波粒二象性；频率低、波长长时波动性显著，频率高、波长短时粒子性显著。

光子动量$$p = \frac{h}{\lambda}$$光子具有动量
能量与波长$$E = \frac{hc}{\lambda}$$与波长成反比
  • 光的干涉、衍射说明波动性，光电效应、康普顿效应说明粒子性。
  • 光的频率越高、波长越短，粒子性越显著。
易错提醒｜概率波的强度反映光子出现的概率，不能把光子理解为经典意义上的粒子。

6康普顿效应

$X$ 射线被物质散射后波长变长的现象叫康普顿效应，说明光子与电子碰撞时动量守恒，光子具有动量。

光子动量$$p = \frac{h}{\lambda}$$碰撞中的动量
波长变化$$\Delta\lambda = \lambda' - \lambda \geq 0$$散射后波长变长
  • 康普顿效应证明光子除能量外还具有动量，进一步支持了光子说。
  • 波长变长说明光子把部分能量传给了电子。
易错提醒｜康普顿效应中光子被散射后能量减小、频率降低、波长变长。

5.2原子结构与能级

掌握原子的核式结构与玻尔理论，理解氢原子能级、跃迁与光谱。

1原子核式结构模型

卢瑟福通过 $\alpha$ 粒子散射实验提出原子核式结构模型：原子中心有一个很小的核，集中了全部正电荷和几乎全部质量。

库仑力$$F = k\frac{q_1q_2}{r^{2}}$$散射的力学基础
散射现象$$\text{极少数大角度偏转}$$说明原子核很小
  • 绝大多数 $\alpha$ 粒子几乎沿直线穿过，极少数发生大角度偏转。
  • 核式结构说明原子的质量和正电荷集中在很小的原子核内。
易错提醒｜$\alpha$ 粒子散射实验否定了汤姆孙的枣糕模型；原子核半径的数量级约为 $10^{-15}\,\mathrm{m}$。

2玻尔理论

玻尔在核式结构基础上提出三条假设：轨道量子化、能量量子化（定态）和跃迁假说。

跃迁条件$$h\nu = E_m - E_n$$吸收或放出光子
轨道量子化$$r_n = n^{2}r_1$$氢原子的轨道半径
能级公式$$E_n = \frac{E_1}{n^{2}}$$$E_1 = -13.6\,\mathrm{eV}$
  • 原子只能处于一系列分立的能量状态（定态），必须吸收或辐射特定能量才能跃迁。
  • 氢原子的能级随量子数增大而升高（负值绝对值减小）。
易错提醒｜原子跃迁吸收或辐射的光子能量必须等于两能级之差，多余的能量不被吸收。

3氢原子能级与光谱

氢原子从高能级向低能级跃迁时辐射光子，形成线状光谱；不同能级间的跃迁对应不同的谱线。

能级公式$$E_n = -\frac{13.6}{n^{2}}\,\mathrm{eV}$$氢原子的能级
跃迁光子$$h\nu = E_m - E_n$$辐射或吸收光子
谱线条数$$N = \frac{n(n-1)}{2}$$$n$ 个能级间的跃迁数
  • 大量氢原子从 $n$ 个能级间可能辐射的谱线条数为 $n(n-1)/2$。
  • 电离是指电子从某能级跃迁到无穷远（能级趋于零）的过程。
易错提醒｜大量氢原子能级跃迁的谱线数用组合公式计算，而单个原子最多辐射 $n-1$ 条谱线。

4原子跃迁中的能量问题

原子跃迁时吸收或放出能量；由光子激发和由实物粒子碰撞引起的跃迁具有不同特点。

光子跃迁$$h\nu = E_m - E_n$$能量必须恰好相等
粒子碰撞$$\Delta E \geq E_m - E_n$$实物粒子能量可以大于能级差
  • 光子激发要求能量恰好等于能级差；实物粒子碰撞则能量可以大于能级差，多余部分转化为动能。
  • 电离时吸收的能量应不小于电离能。
易错提醒｜光子与实物粒子引起跃迁的条件不同，实物粒子不受能级差恰好相等的限制。

5玻尔理论的局限

玻尔理论成功解释了氢原子光谱，但不能解释多电子原子的光谱，其根本原因是保留了经典理论的局限。

适用对象$$\text{氢原子等类氢体系}$$单电子体系
  • 玻尔理论只适用于氢原子和类氢离子。
  • 量子力学用电子云描述电子在原子核外的空间分布。
易错提醒｜玻尔理论是半经典、半量子的理论，不能解释复杂原子的光谱。

5.3原子核与核反应

掌握天然放射现象、衰变规律、半衰期、核反应方程、质量亏损与质能方程。

1天然放射现象与三种射线

放射性元素自发地放出射线的现象叫天然放射现象，放射线包括 $\alpha$、$\beta$、$\gamma$ 三种射线。

$\alpha$ 衰变$${}^{A}_{Z}X \to {}^{A-4}_{Z-2}Y + {}^{4}_{2}\mathrm{He}$$放出氦核
$\beta$ 衰变$${}^{A}_{Z}X \to {}^{A}_{Z+1}Y + {}^{0}_{-1}\mathrm{e}$$放出电子
$\gamma$ 辐射$${}^{A}_{Z}X^{*} \to {}^{A}_{Z}X + \gamma$$伴随衰变产生
  • $\alpha$ 射线电离能力最强、穿透能力最弱；$\gamma$ 射线穿透能力最强。
  • 衰变过程遵循电荷数与质量数守恒。
易错提醒｜$\beta$ 衰变放出的电子来自原子核内中子的转化，并非核外电子。

2半衰期

放射性元素的原子核有半数发生衰变所需的时间叫半衰期，其长短由核本身决定，与外界条件无关。

剩余核数$$N = N_0\left(\frac{1}{2}\right)^{t/T}$$$T$ 为半衰期
剩余质量$$m = m_0\left(\frac{1}{2}\right)^{t/T}$$与核数成正比
  • 半衰期是统计规律，只对大量原子核有意义。
  • 半衰期与温度、压强、化学状态都无关。
易错提醒｜半衰期是统计概念，不能用于少数几个原子核；外界条件不能改变半衰期。

3核反应与核反应方程

用核反应方程表示原子核的变化，方程两边满足质量数与电荷数守恒；常见反应有衰变、人工转变、裂变和聚变。

发现中子$${}^{9}_{4}\mathrm{Be} + {}^{4}_{2}\mathrm{He} \to {}^{12}_{6}\mathrm{C} + {}^{1}_{0}\mathrm{n}$$查德威克发现中子
重核裂变$${}^{235}_{92}\mathrm{U} + {}^{1}_{0}\mathrm{n} \to {}^{141}_{56}\mathrm{Ba} + {}^{92}_{36}\mathrm{Kr} + 3{}^{1}_{0}\mathrm{n}$$裂变放出中子
轻核聚变$${}^{2}_{1}\mathrm{H} + {}^{3}_{1}\mathrm{H} \to {}^{4}_{2}\mathrm{He} + {}^{1}_{0}\mathrm{n}$$聚变放出能量
  • 核反应方程遵循质量数守恒和电荷数守恒。
  • 裂变和聚变都放出巨大能量，都伴随质量亏损。
易错提醒｜核反应中质量数守恒但质量不守恒（有质量亏损）；电荷数守恒对应电荷守恒。

4质量亏损与质能方程

核反应中反应前后质量之差叫质量亏损；亏损的质量转化为能量，可由质能方程计算释放的能量。

质能方程$$E = mc^{2}$$质量与能量的联系
释放能量$$\Delta E = \Delta m c^{2}$$质量亏损对应能量
单位换算$$1\,\mathrm{u} = 931.5\,\mathrm{MeV}/c^{2}$$原子质量单位
  • 质量亏损对应释放的能量，是核能的来源。
  • 重核裂变和轻核聚变都因质量亏损而放出能量。
易错提醒｜核能计算要统一单位；$\Delta m$ 是质量亏损，而不是反应物的总质量。

5结合能与比结合能

把原子核分解为自由核子所需的能量叫结合能；结合能与核子数之比叫比结合能，比结合能越大原子核越稳定。

结合能$$E_b = \Delta m c^{2}$$核子结合成核时释放的能量
比结合能$$\bar{E}_b = \frac{E_b}{A}$$$A$ 为核子数
  • 比结合能越大，原子核越稳定，中等质量的核最稳定。
  • 重核裂变和轻核聚变都向比结合能更大的方向进行，从而放出能量。
易错提醒｜结合能大不代表稳定，要看比结合能；铁附近的核比结合能最大。

6核反应中的守恒与核能利用

核反应过程满足电荷数守恒、质量数守恒、能量守恒和动量守恒；核能可用于发电，但需防护辐射。

动量守恒$$m_1v_1 = m_2v_2$$衰变中的动量守恒
能量守恒$$\Delta E = \Delta m c^{2}$$释放核能
  • 核反应遵循电荷数、质量数、能量和动量守恒定律。
  • 核能发电利用的是重核裂变的链式反应。
易错提醒｜核裂变链式反应需要达到临界体积；核反应中的守恒量不能遗漏动量守恒。

5.4相对论简介

了解狭义相对论的两条基本假设以及时空相对性、质速关系和质能关系。

1狭义相对论的两条基本假设

相对性原理和光速不变原理是狭义相对论的两条基本假设。

相对性原理$$\text{一切惯性系等价}$$物理规律形式相同
光速不变$$c = \text{常量}$$与光源、观察者的运动无关
  • 狭义相对论适用于惯性系，物理规律在一切惯性系中形式相同。
  • 真空中的光速在任何惯性系中都相同，与光源和观察者的运动无关。
易错提醒｜光速不变原理与经典的速度叠加相矛盾，是相对论的出发点。

2时间延缓与长度收缩

相对论指出，运动的时钟变慢（时间延缓），运动的尺子沿运动方向变短（长度收缩），这就是时空的相对性。

时间延缓$$\Delta t = \frac{\Delta t_0}{\sqrt{1 - v^{2}/c^{2}}}$$动钟变慢
长度收缩$$L = L_0\sqrt{1 - v^{2}/c^{2}}$$动尺沿运动方向变短
  • 运动的时钟变慢，运动的物体沿运动方向长度收缩。
  • 时间延缓与长度收缩都只在速度接近光速时才明显。
易错提醒｜时间延缓是相对的，双方都认为对方的钟慢；日常低速下效应可以忽略。

3相对论质量与质能关系

相对论中物体的质量随速度增大而增大；质量和能量等价，由质能方程联系。

相对论质量$$m = \frac{m_0}{\sqrt{1 - v^{2}/c^{2}}}$$$m_0$ 为静质量
质能关系$$E = mc^{2}$$物体的总能量
静能$$E_0 = m_0 c^{2}$$物体静止时的能量
  • 物体速度越大质量越大，接近光速时质量趋于无穷，因此无法达到光速。
  • 质能关系说明质量与能量可以相互联系，是核能的依据。
易错提醒｜静质量不随速度变化；只有总质量随速度增大。

4相对论的验证与意义

相对论已被大量实验证实，例如高速粒子的寿命延长、核反应释放能量、原子钟实验等。

质能方程应用$$\Delta E = \Delta m c^{2}$$核能的来源
速度限制$$v \leq c$$实物粒子的速度不能超过光速
  • 相对论在速度接近光速的情形下与实验符合得很好。
  • 任何实物粒子的运动速度都小于真空中的光速。
易错提醒｜相对论并不否定经典力学，低速时相对论的结论与经典力学一致。
