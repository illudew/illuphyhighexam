整体法与隔离法基础

连接体（绳、杆、弹簧、叠放、环）系统受力与加速度分析。

🎯 核心思想
求系统外力或共同加速度时用整体法（把系统当一个质点）；求系统内部相互作用力时必须隔离其中一部分。二者配合使用，先整体求加速度，再隔离求内力。
  1. 明确研究系统，判断系统内各物体加速度是否相同。
  2. 整体法：只分析系统所受外力，列牛顿第二定律求整体加速度。
  3. 隔离法：挑受力最少的那个物体单独画受力图，列方程求相互作用力。
  4. 对结果做量纲与极限检验（如把某质量趋于零看是否合理）。
🧩 典型例题
光滑水平面上 $A$、$B$ 两物块（质量 $m_A,m_B$）由轻绳相连，用水平恒力 $F$ 拉 $A$ 运动。整体法：$a=\dfrac{F}{m_A+m_B}$；隔离 $B$：绳张力 $T=m_B a=\dfrac{m_B F}{m_A+m_B}$。
易错提醒｜整体法不能求内力（绳张力、接触面弹力）；隔离时漏画某力是最常见失分点，务必将所选物体与外界的所有作用都画出。
🎯 口诀：外力用整体，内力必隔离；先整体求 $a$，再隔离求力。

图象法（斜率与面积）基础

运动学、动力学、变力做功、冲量等，凡题目给出或可画出函数图象者皆可用。

🎯 核心思想
图象的斜率、面积、截距、交点都有物理意义：$x$-$t$ 斜率是速度，$v$-$t$ 斜率是加速度、面积是位移，$F$-$x$ 面积是功，$F$-$t$ 面积是冲量，$U$-$I$ 图线上点与原点连线斜率为电阻。看懂图比解方程更快捷。
  1. 看清横、纵坐标的物理量与单位。
  2. 写出该图线斜率与面积分别代表什么物理量。
  3. 用几何（斜率、面积、截距）提取数据。
  4. 与物理方程联立求解，注意正负号。
🧩 典型例题
$v$-$t$ 图线下方梯形面积即位移 $s=\dfrac{v_1+v_2}{2}t$，这正是平均速度法的几何来源；斜率为加速度。
易错提醒｜时间轴下方的面积取负（反向位移）；不要凭曲线形状臆断结论，先确认坐标轴是什么量。
🎯 口诀：斜率看变化率，面积看累积量。

微元法进阶

力或速度连续变化的问题：变力做功、连续质量（水流、链条、传送带）、曲线上取小段。

🎯 核心思想
把连续过程分割为无穷多小段，每段内近似为匀变速或恒力，写出微元表达式 $\Delta W=F\Delta x$ 或 $\Delta s=v\Delta t$，再累加（转化为图象面积或积分）。
  1. 取一小段 $\Delta x$ 或 $\Delta t$。
  2. 在该小段内把变化的量视为恒量。
  3. 写出微元量的表达式。
  4. 对全部微元累加求和（或求面积）。
🧩 典型例题
求压缩弹簧所做的功：取位移元 $\Delta x$，$\Delta W=F\Delta x=kx\Delta x$，累加即 $F$-$x$ 图线下三角形面积 $\dfrac12 kx^2$。
易错提醒｜微元近似成立的前提是段足够小；累加时不要漏掉正负号与积分的上下限。
🎯 口诀：化整为零，先微后积。

等效法（等效重力场·等效电路·等效电源）进阶

复合场中的带电体、复杂电路、结构陌生但可化简的问题。

🎯 核心思想
用效果相同的简单模型替代复杂对象：把重力与电场力合成为「等效重力」$g'=\dfrac{mg+qE}{m}$；把复杂电路串并联化简为等效电阻；用戴维南等效把含源二端网络化为一个电源与电阻。
  1. 识别原始系统与各分作用。
  2. 把分作用合成为等效量（等效重力/等效电阻/等效电动势）。
  3. 在等效模型里套用熟悉结论求解。
  4. 把结果还原为原题中各分物理量。
🧩 典型例题
带电小球在竖直匀强电场中，$g'=\dfrac{mg+qE}{m}$ 当作等效重力，竖直圆周、单摆、斜面问题全部照搬套用。
易错提醒｜等效是「效果等效」，还原时各分力的大小、方向仍需分别说明；等效电源内阻不可漏。
🎯 口诀：效果相同即可替换，等效重、等效源。

极限法与极值法进阶

动态过程中的临界、最值问题：绳长趋于零、夹角趋于 $0^\circ$ 或 $90^\circ$、求最大最小力。

🎯 核心思想
让某物理量趋于 $0$ 或无穷以检验结论、判断临界；或建立目标函数后用数学工具（二次函数判别式、三角函数合成、均值不等式）求极值。
  1. 明确自变量与目标函数，写出函数关系。
  2. 用判别式、均值不等式或三角函数求极值。
  3. 判断极值点对应的物理状态是否可实现。
  4. 给出极值条件与结果。
🧩 典型例题
用两根互成角度的力合成时，最小值取夹角 $0^\circ$、最大值取同一方向相加；两力垂直时合力 $\sqrt{F_1^2+F_2^2}$。
易错提醒｜极限值必须物理可实现，不能出现负质量、虚数速度等无意义结果；求极值勿越定义域。
🎯 口诀：推向极端看结论，函数求极找临界。

对称法基础

具有对称性的运动与场：竖直上抛、类平抛、磁场中圆弧、对称电场、弹性碰撞。

🎯 核心思想
利用时间对称、空间对称、速度对称，把计算量减半或直接得结论：竖直上抛上升与下降时间相等、速度等大反向；水平入射匀强磁场的圆弧关于入射点对称。
  1. 判断是否存在对称轴或对称面。
  2. 找出对称的两个物理量（时间、速度、位移）。
  3. 只计算其中一半。
  4. 对称还原出另一半。
🧩 典型例题
竖直上抛物体：上升到最高点与从最高点落回同一高度所用时间相等，速度大小相等、方向相反。
易错提醒｜存在空气阻力或持续外力时对称性被破坏，不可盲目套用。
🎯 口诀：对称处省一半力，抓住对称算一半。

逆向思维法基础

末态已知、初态未知的问题：刹车问题、匀减速到零、平抛的反演。

🎯 核心思想
把「减速到零」看成反向的「从零匀加速」，把末状态当作初状态，方程往往更简单；匀变速直线运动可逆，非匀变速过程不可逆。
  1. 判断该过程是否可逆（是否为匀变速或对称过程）。
  2. 把末状态当作起点。
  3. 套用初速为零的匀变速公式。
  4. 还原方向与时间得到答案。
🧩 典型例题
汽车刹车可视为反向的初速为零匀加速，末速为零时 $s=\dfrac{v_0}{2}t$，用逆向法比解二次方程快。
易错提醒｜只有匀变速或对称过程才可逆；阻力与速度相关的变减速不可逆。
🎯 口诀：正推困难倒着算，减速到零当加速。

假设法进阶

静摩擦方向未知、绳松紧不确定、临界状态判断、电流方向待定。

🎯 核心思想
先假设某种状态（如摩擦沿斜面向上、绳已拉直、接触面有弹力），代入求解，再由结果的正负与物理合理性判断假设真假并修正。
  1. 假设待定状态（一次只设一个）。
  2. 按假设画受力图并列方程。
  3. 解出关键未知量。
  4. 依据结果的符号与物理合理性判断假设真伪。
🧩 典型例题
判断斜面上物体是否滑动：先假设静止，用平衡求出所需静摩擦 $f$，若 $f\le f_{max}=\mu mg\cos\theta$ 则确实静止。
易错提醒｜避免同时做多个相互矛盾的假设；结论要用物理常识检验（如弹力不能为负）。
🎯 口诀：先设后验，符号定真假。

比例法基础

同一模型下只有单一量改变，或本身成比例关系的问题（天体、碰撞、串并联）。

🎯 核心思想
写出物理量之间的正比反比关系（如初速为零时 $s\propto t^2$、万有引力 $F\propto\dfrac{1}{r^2}$、串并联分流分压），抓住不变量直接用比例求解，避开具体数值。
  1. 写出基本关系式。
  2. 找出保持不变的一批量。
  3. 把关系式化为两状态之比。
  4. 代入已知倍数求解。
🧩 典型例题
初速为零匀加速：第 $1,2,3$ s 内位移之比为 $1:3:5$；通过连续相等位移所用时间之比为 $1:(\sqrt2-1):(\sqrt3-\sqrt2)$。
易错提醒｜比例式成立的前提是其它量恒定，务必先确认谁是那个不变量。
🎯 口诀：抓住不变量，列出正反比。

控制变量法基础

多因素问题的探究实验，或需要判断某量如何依赖另一量。

🎯 核心思想
研究一个量随另一个量变化时，必须让其余影响量保持恒定，才能得到单一、清晰的因果关系。
  1. 找出影响结果的全部因素。
  2. 固定其余因素保持不变。
  3. 每次只改变一个因素并记录结果。
  4. 归纳该量与被改变因素的关系。
🧩 典型例题
探究牛顿第二定律：先保持质量不变，找 $a$ 与 $F$ 成正比；再保持拉力不变，找 $a$ 与 $m$ 成反比。
易错提醒｜若多个量同时变化，结论无法归因，实验结论不成立。
🎯 口诀：单变量研究，多因素分开。

类比法进阶

把陌生情境迁移到熟悉模型：电场与重力场、电流与水流、圆周运动与天体运动。

🎯 核心思想
两个物理过程若数学结构相同，就可把熟悉模型的结论与方法迁移过来。如库仑力 $F=k\dfrac{q_1q_2}{r^2}$ 与万有引力 $F=G\dfrac{m_1m_2}{r^2}$ 同构。
  1. 找出两问题在数学结构上的相同点。
  2. 建立物理量之间的对应关系。
  3. 把熟悉模型的结论与方法迁移过来。
  4. 回到本题解释并检验适用条件。
🧩 典型例题
电子绕核运动可类比卫星绕地球运动，$F=k\dfrac{q_1q_2}{r^2}$ 对应 $F=G\dfrac{m_1m_2}{r^2}$，直接用圆周运动与能量公式。
易错提醒｜类比只在数学形式上成立，物理本质与适用条件仍需甄别（如电荷有正负、引力只有吸引）。
🎯 口诀：形似即可迁移，本质仍需甄别。

估算法进阶

数量级选择题、无精确数据的题目、验证选项是否合理。

🎯 核心思想
用常见物理量的数量级和合理近似，快速得到数量级正确的结果，或判断某个选项是否荒谬。
  1. 找出已知的数量级量。
  2. 对未知量做合理近似。
  3. 做量纲与数量级运算。
  4. 与选项或常识比对。
🧩 典型例题
估算人跑步功率：$P\approx mgv$，取 $mg\approx600\,\mathrm{N}$、$v\approx5\,\mathrm{m/s}$，数量级约 $10^3$ W。
易错提醒｜估算只保证数量级，不能当精确解；注意统一到国际单位。
🎯 口诀：抓数量级，舍次要项。

传送带模型（水平·倾斜）进阶

物体放上传送带、传送带匀速运行、倾斜传送带上物体运动。

🎯 核心思想
核心分界点是「共速」：共速前摩擦力由相对运动方向决定；共速后要判断能否维持相对静止（静摩擦是否足够、重力分力是否继续驱动）。分阶段求解各段加速度、时间、位移。
  1. 判断物体相对传送带的运动方向，定摩擦力方向。
  2. 求共速前的加速度与达到共速所需时间、位移。
  3. 在共速点判断能否共速（静摩擦或重力分力是否满足）。
  4. 共速后重新受力分析，分段继续求解。
🧩 典型例题
水平传送带以 $v$ 匀速，物块初速为零：先受滑动摩擦 $a=\mu g$ 加速，达 $v$ 后若无他力则一起匀速；相对滑动生热 $Q=f\Delta s$。
易错提醒｜共速后不一定是匀速，倾斜带上重力分力可能继续驱动二次加速；生热用相对位移 $\Delta s$，不是物体或皮带的位移。
🎯 口诀：共速是分界，前后各算一段。

板块（滑板滑块）模型进阶

滑块在长木板或小车上滑动，木板可动、地面是否光滑待定。

🎯 核心思想
分别隔离滑块与木板求各自加速度（动摩擦方向由相对运动定），再由共速条件求相对滑动的时间与位移；地面光滑时系统动量守恒。相对位移 $\Delta s=s_1-s_2$ 对应摩擦生热。
  1. 分别隔离滑块与木板，求各自加速度。
  2. 写出两物的速度表达式，找共速条件。
  3. 求相对位移 $\Delta s=s_1-s_2$。
  4. 用能量或动量关系求末状态或生热。
🧩 典型例题
滑块 $m$ 以 $v_0$ 滑上静止长木板 $M$（地面光滑）：$a_1=\mu g$，$a_2=\dfrac{\mu mg}{M}$，共速后一起匀速，生热 $Q=\mu mg\,\Delta s$。
易错提醒｜相对位移不等于任一物体的位移；能否共速要看地面摩擦与加速度方向，共速后二者可能一起减速。
🎯 口诀：分体求 $a$，共速定终。

弹簧模型进阶

弹簧连接体、竖直弹簧振子、弹簧与能量、弹力随形变变化。

🎯 核心思想
弹簧弹力 $F=kx$ 随形变变化，力的变化是渐进的；加速度为零处（合力为零）速度最大；弹性势能 $E_p=\dfrac12 kx^2$。求加速度用整体，求弹力用隔离。
  1. 确定平衡位置（合力为零处）。
  2. 判断加速度与速度随位置的变化趋势。
  3. 用能量守恒联系形变量与速度。
  4. 利用简谐运动的对称性求极值位置。
🧩 典型例题
竖直弹簧振子在平衡位置速度最大；简谐运动中相对平衡位置对称的两点加速度等大反向。
易错提醒｜弹力方向由形变性质决定（拉伸为拉力、压缩为压力），判反是常见错误；一端固定时弹力直接作用于物块。
🎯 口诀：形变定弹力，平衡处速度最大。

连接体模型进阶

绳、杆、弹簧连接的多个物体，含滑轮、斜面、垂直方向等约束。

🎯 核心思想
系统内力时先整体求加速度，再隔离求绳（杆）力。轻绳不可伸长、只能拉，沿绳方向加速度分量相同；轻杆不可伸长但可转，能提供任意方向的力。
  1. 判断约束类型（绳 / 杆 / 弹簧）。
  2. 把加速度沿绳方向分解，求系统加速度。
  3. 整体与隔离组合求出绳力或杆力。
  4. 检验约束条件是否满足（绳是否绷紧等）。
🧩 典型例题
定滑轮连接 $A$、$B$：系统加速度 $a=\dfrac{F_{合}}{m_A+m_B}$，隔离一侧即可求绳张力 $T$。
易错提醒｜轻杆既能拉又能支，与轻绳只能拉不同；有加速度时杆力一般不沿杆方向。
🎯 口诀：绳沿绳、杆任意；先整体后隔离。

圆周运动临界模型（绳·杆·管道·外轨）进阶

竖直平面内圆周运动，含绳模型、杆模型、光滑圆弧管道、轨道内外侧。

🎯 核心思想
只提供单侧支持的是「绳模型」，最高点最小速度 $v=\sqrt{gR}$（重力恰提供向心力）；能提供双向力的是「杆 / 管道模型」，最高点临界速度为零，只要 $v\ge 0$ 且通过最高点即可过顶。
  1. 判断约束是单侧（绳/内侧轨道）还是双向（杆/管道）。
  2. 确定最高点的最小速度。
  3. 列最高点、最低点的向心力方程。
  4. 用机械能守恒联系两端速度。
🧩 典型例题
绳（或圆轨道内侧）最高点最小速度 $v=\sqrt{gR}$，此时 $mg=m\dfrac{v^2}{R}$；杆（管道）最高点 $v=0$ 也能过顶。
易错提醒｜绳模型最低点绳力最大、最高点最小；不要把杆模型的最小速度也写成 $\sqrt{gR}$。
🎯 口诀：绳要过顶须 $\sqrt{gR}$，杆能过顶可为零。

类平抛运动的分解进阶

带电粒子初速垂直于匀强电场方向射入、通用平抛类运动。

🎯 核心思想
把曲线运动分解为沿初速方向的匀速直线运动和沿合外力方向的匀加速直线运动，两个方向独立，用「时间相等」把它们关联。
  1. 确定初速方向与合外力方向（两者垂直）。
  2. 两方向分别列出匀速与匀加速的方程。
  3. 用运动时间相等把两方向联系起来。
  4. 合成速度与位移，注意方向角。
🧩 典型例题
电子以 $v_0$ 垂直电场方向射入，偏转量 $y=\dfrac12 a t^2=\dfrac12\dfrac{qE}{m}\left(\dfrac{L}{v_0}\right)^2$。
易错提醒｜分解方向要沿合外力方向（不一定是竖直）；粒子离开电场后做匀速直线运动，需另起一段计算。
🎯 口诀：一匀速一匀变，时间相连。

带电粒子在磁场中运动三步法高阶

带电粒子在匀强磁场中做匀速圆周运动，求半径、圆心、时间和偏转。

🎯 核心思想
洛伦兹力提供向心力 $qvB=\dfrac{mv^2}{r}$，半径 $r=\dfrac{mv}{qB}$、周期 $T=\dfrac{2\pi m}{qB}$。三步：定圆心（两速度垂线的交点、或弦的中垂线与半径的交点）、求半径、算圆心角 $\theta$ 并由 $t=\dfrac{\theta}{2\pi}T=\dfrac{\theta m}{qB}$ 求时间。
  1. 画出入射、出射速度方向并作法线。
  2. 两速度垂线（或弦中垂线）的交点即为圆心。
  3. 用几何关系求半径与弦长。
  4. 求圆心角（弦切角是圆心角的一半），算运动时间。
🧩 典型例题
粒子垂直边界射入半无限磁场，出射弧对应圆心角 $\theta$，时间 $t=\dfrac{\theta m}{qB}$，弦长 $L=2r\sin\dfrac{\theta}{2}$。
易错提醒｜分清「弦切角」「圆心角」「速度偏转角」的关系：弦切角等于圆心角的一半；圆心角等于速度偏转角。
🎯 口诀：定心、求半径、算角度与时间。

磁场中的临界与多解问题高阶

粒子能否射出边界、运动范围、速度大小或方向不定带来的多解。

🎯 核心思想
半径 $r=\dfrac{mv}{qB}$ 随速度增大而增大，临界往往出现在轨迹与边界「相切」处。速度方向不定时用旋转圆（绕入射点转动半径），速度大小不定时用缩放圆（改变半径）讨论多解。
  1. 找出临界几何关系（相切、过端点、恰好射出）。
  2. 用伸缩法（改变半径）确定能否射出的范围。
  3. 方向不定时用旋转圆，逐一分情况讨论。
  4. 对每种情况验证并汇总。
🧩 典型例题
粒子从一点以不同方向射入，能到达区域的边界由轨迹与边界相切确定，最大半径对应恰好与边界相切。
易错提醒｜多解问题要讨论完全，别漏掉反向进入或绕行一周（圆心角超过 $2\pi$）的情况。
🎯 口诀：相切定临界，旋转缩放找多解。

复合场模型（选择器·发电机·流量计·霍尔效应）高阶

电场与磁场并存，粒子做直线或圆周运动，工业电磁器件模型。

🎯 核心思想
做直线运动时电场力与洛伦兹力平衡 $qE=qvB$，得 $v=\dfrac{E}{B}$（与电荷量、符号无关）；做圆周时只有洛伦兹力提供向心力。器件类先由受力平衡求电动势或电压。
  1. 判断运动轨迹是直线还是圆周。
  2. 直线：用二力平衡列 $qE=qvB$。
  3. 圆周：用洛伦兹力提供向心力。
  4. 器件类由平衡关系求 $U$、$E$、$Q$ 等待求量。
🧩 典型例题
速度选择器 $qE=qvB\Rightarrow v=\dfrac{E}{B}$，不选电荷种类；磁流体发电机 $U=Bdv$；霍尔效应 $U_H=\dfrac{IB}{nqd}$。
易错提醒｜复合场中是否计入重力要先判断：离子、电子通常忽略，宏观带电体（小球、油滴）常不能忽略。
🎯 口诀：直线二力平，曲线洛伦兹。

电磁感应单杆导轨模型高阶

导体棒在导轨上切割磁感线，受拉力、重力或连接电阻/电容。

🎯 核心思想
沿因果链分析：$E=BLv\to I=\dfrac{E}{R+r}\to F_A=\dfrac{B^2L^2v}{R+r}$。速度越大安培力越大，加速度逐渐减小，最终趋于匀速（$a=0$，$F_A=F_{外}$）。
  1. 判断感应电动势来源与电流方向（右手定则）。
  2. 写出安培力表达式 $F_A=\dfrac{B^2L^2v}{R+r}$。
  3. 列牛顿第二定律求 $a$ 随 $v$ 的变化。
  4. 令 $a=0$ 求最终最大速度，再用能量求焦耳热。
🧩 典型例题
杆在恒力 $F$ 下最终匀速：$F=\dfrac{B^2L^2v_m}{R+r}\Rightarrow v_m=\dfrac{F(R+r)}{B^2L^2}$，焦耳热 $Q=Fs-\dfrac12 mv_m^2$。
易错提醒｜速度最大对应加速度为零（不是力最大）；电容回路中电流与加速度相关，不能盲目套欧姆定律。
🎯 口诀：速度越大安培力越大，加速度为零速度最大。

双杆导轨与动量观点高阶

两根导体棒置于同一磁场导轨，之间相互作用或一杆受冲量。

🎯 核心思想
双杆系统所受安培力等大反向、合力为零（安培力是内力），故动量守恒；两杆速度趋于使相对速度为零（回路总电动势相消、电流为零）的终态。配合能量守恒求总焦耳热。
  1. 判断系统外力之和是否为零。
  2. 由动量守恒求共同速度或末速度。
  3. 由能量守恒求总焦耳热。
  4. 按电阻比例分配各杆热量。
🧩 典型例题
光滑导轨上两杆（质量 $m$、$M$）初速 $v_0$ 与静止：动量守恒 $mv_0=(m+M)v$，焦耳热 $Q=\dfrac12 mv_0^2-\dfrac12(m+M)v^2$。
易错提醒｜电流为零对应回路总电动势为零（速度相等）；若导轨不水平或存在外磁场力矩，动量不再守恒，需改用动量定理。
🎯 口诀：安培力等大反向，双杆动量守恒。

变压器动态分析三步进阶

理想变压器负载变化时，各线圈电压、电流、功率的变化分析。

🎯 核心思想
理想变压器：电压比等于匝数比 $\dfrac{U_1}{U_2}=\dfrac{n_1}{n_2}$，功率守恒 $P_1=P_2$（电流与匝数成反比只对单个副线圈成立）。分析顺序：先电压（由输入决定）、再副线圈电流（由负载决定）、最后原线圈电流（由功率决定）。
  1. 由匝数比确定副线圈电压（输入电压不变则其不变）。
  2. 由负载求副线圈电流 $I_2=\dfrac{U_2}{R}$。
  3. 由功率守恒求原线圈电流 $I_1$。
  4. 判断滑片、开关变化时各量的增减方向。
🧩 典型例题
副线圈负载电阻减小时，$U_2$ 不变，$I_2=\dfrac{U_2}{R}$ 增大，$P_2$ 增大，$I_1$ 随之增大。
易错提醒｜电流与匝数成反比只在单一副线圈时成立，多副线圈只能用功率守恒；变压器不改变频率。
🎯 口诀：电压看匝比，电流看功率。

电路动态分析（串反并同）进阶

含滑动变阻器的串并联电路，用闭合电路欧姆定律分析各量随滑片的变化。

🎯 核心思想
先判断电路结构，再用「串反并同」：与变阻器串联的元件，其电流、电压变化趋势与变阻器阻值变化相反；与之并联的支路变化趋势相同。推理顺序：先局部、再整体、再局部。
  1. 判断滑片移动时总电阻如何变化。
  2. 由 $I=\dfrac{E}{R+r}$ 判断干路电流。
  3. 由 $U_{外}=E-Ir$ 判断路端电压。
  4. 用「串反并同」或分压分流判断各支路。
🧩 典型例题
变阻器 $R$ 增大：总电阻增大、干路电流减小、路端电压增大；与它串联的电阻电压减小，与它并联的支路电压增大。
易错提醒｜「串反并同」只判断变化趋势，具体数值仍需计算；注意电源内阻不能忽略。
🎯 口诀：串反并同，先总后分。

气体状态变化与图象进阶

一定质量理想气体的状态变化、$p$-$V$、$p$-$T$、$V$-$T$ 图象。

🎯 核心思想
用 $\dfrac{pV}{T}=C$ 判断各图象的图线形状与过程；$p$-$V$ 图线下面积表示气体做功；结合热力学第一定律 $W+Q=\Delta U$（外界对气体做功取正）判断做功与吸放热。
  1. 确认气体质量是否恒定。
  2. 写出初、末状态的三个参量。
  3. 用状态方程或图象判断是什么过程。
  4. 用热力学第一定律判断做功与吸放热。
🧩 典型例题
等温线在 $p$-$V$ 图为双曲线，等容线在 $p$-$T$ 图为过原点的直线；气体膨胀对外做功 $W<0$（气体内能由温度定）。
易错提醒｜符号约定要统一（外界对气体做功为正）；对理想气体，温度升高则内能一定增大。
🎯 口诀：三参量一方程，图象面积看做功。

全反射与光路作图进阶

光在介质界面的反射折射、光纤、棱镜、全反射现象。

🎯 核心思想
折射定律 $n=\dfrac{\sin\theta_1}{\sin\theta_2}$；光由光密介质射向光疏介质，入射角大于临界角 $C$（$\sin C=\dfrac1n$）时发生全反射。作图先画法线、标角度，再判断是否满足全反射。
  1. 在入射点画出法线。
  2. 判断光疏、光密介质关系。
  3. 用折射定律求折射角，或判断是否全反射。
  4. 画出反射光线或折射光线，标出方向。
🧩 典型例题
光从水（$n=\dfrac43$）射向空气，$\sin C=\dfrac34$，入射角大于 $C$ 时全反射，无折射光。
易错提醒｜全反射只发生在光密射向光疏时；所有角度一律以法线为基准，不是与界面的夹角。
🎯 口诀：密射疏、超临界，全反射。

二级结论速用基础

匀变速直线运动、卫星、碰撞等有固定二级结论可直接套用的题型。

🎯 核心思想
熟记常用二级结论，省去现场推导：中间时刻速度 $v_{t/2}=\bar v=\dfrac{v_0+v}{2}$；匀变速逐差 $\Delta s=aT^2$；初速为零的比例结论；卫星「黄金代换」$GM=gR^2$ 与密度 $\rho=\dfrac{3\pi}{GT^2}$。
  1. 判断题目属于哪个已结论化的模型。
  2. 核对结论的适用条件是否满足。
  3. 代入已知量计算。
  4. 用单位或极限值检验结果。
🧩 典型例题
近表面卫星：由 $\dfrac{GMm}{R^2}=m\dfrac{4\pi^2}{T^2}R$ 与 $\rho=\dfrac{M}{\frac43\pi R^3}$ 得 $\rho=\dfrac{3\pi}{GT^2}$。
易错提醒｜二级结论都有前置条件（如匀变速、初速为零、忽略自转），条件不符直接套用会大错。
🎯 口诀：结论要牢记，条件先核对。

平均速度法基础

匀变速直线运动中求位移或时间，尤其初、末速度已知的情形。

🎯 核心思想
匀变速运动中平均速度等于初末速度的平均值，也等于中间时刻的瞬时速度：$\bar v=\dfrac{v_0+v}{2}=v_{t/2}$，位移 $s=\bar v\,t$。
  1. 确认是匀变速直线运动。
  2. 求出初、末速度或中间时刻速度。
  3. 用 $s=\bar v\,t$ 求位移或时间。
🧩 典型例题
物体从 $v_0$ 匀减速到零，位移 $s=\dfrac{v_0+0}{2}t=\dfrac{v_0}{2}t$，比用位移公式更省事。
易错提醒｜只有匀变速才成立；非匀变速时 $v_{t/2}\ne\bar v$，不能套用。
🎯 口诀：平均速度等于中间时刻速度。

图象面积法（速算）进阶

快速求变力做功、冲量、位移等累积量。

🎯 核心思想
$v$-$t$ 面积是位移、$F$-$x$ 面积是功、$F$-$t$ 面积是冲量、$p$-$V$ 面积是功；面积可正可负，正负由图形相对坐标轴的位置决定。
  1. 找出对应的横纵坐标物理量。
  2. 判断面积的正负。
  3. 用三角形、梯形等几何公式求面积。
🧩 典型例题
弹簧弹力 $F=kx$，压缩 $x_0$ 时弹力做功大小为 $F$-$x$ 三角形面积 $\dfrac12 kx_0^2$，即弹性势能。
易错提醒｜取面积时横轴单位要统一；时间轴下方的位移为负，别只取大小。
🎯 口诀：面积即累积，正负看上下。

三力平衡的动态三角形与相似三角形法进阶

一个力大小方向恒定、一个力方向不变、第三个力大小方向变化时判断力的增减；或力与几何长度成比例。

🎯 核心思想
三力平衡可首尾相接成闭合矢量三角形；动态分析看三角形各边如何随角度变化。若力与几何长度一一对应，则用相似三角形法，用 $\dfrac{F_1}{L_1}=\dfrac{F_2}{L_2}=\dfrac{F_3}{L_3}$ 求力。
  1. 画出闭合的力三角形。
  2. 确定哪个力大小方向不变、哪个力方向不变。
  3. 让变化的力转动，观察各边长（力的大小）如何变化。
  4. 若有几何相似关系则列对应边比例求解。
🧩 典型例题
绳通过定滑轮悬挂重物、绳另一端沿杆平移：力三角形与几何三角形相似，用对应边比例 $\dfrac{T}{L}=\dfrac{G}{h}$ 求绳力。
易错提醒｜动态三角形只适用于三力且其中一力恒定；方向变化的顶点位置要判断准确。
🎯 口诀：三力闭合成三角，力变边变看长短。

弦长公式与磁偏转几何高阶

带电粒子在磁场中做圆周运动、磁约束、圆形磁场区域问题。

🎯 核心思想
弦长 $L=2r\sin\dfrac{\theta}{2}$，其中 $\theta$ 为弦所对的圆心角；配合半径公式 $r=\dfrac{mv}{qB}$ 可快速求半径、弦长与时间，避免大量坐标运算。
  1. 找出入射点与出射点的连线（弦）。
  2. 确定弦切角与圆心角的关系（弦切角为圆心角的一半）。
  3. 用弦长公式与半径公式联立求解。
🧩 典型例题
磁偏转中偏转角 $\alpha$ 等于圆心角，弦长 $L=2r\sin\dfrac{\alpha}{2}=\dfrac{2mv}{qB}\sin\dfrac{\alpha}{2}$。
易错提醒｜圆心角、弦切角、偏转角三者别混用；要清楚谁是谁的一半。
🎯 口诀：弦长等于两倍半径乘半角正弦。

比例式速解进阶

相同模型在不同条件下成比例的问题：天体、串并联、碰撞、气体。

🎯 核心思想
抓住不变量，把关系式写成两状态之比，直接比较倍数，省去求具体值。如星球表面 $g=\dfrac{GM}{R^2}$、天体 $T\propto r^{3/2}$。
  1. 写出含不变量的基本关系式。
  2. 化为两个状态的比值。
  3. 代入已知倍数关系得出结论。
🧩 典型例题
星球表面重力加速度 $g=\dfrac{GM}{R^2}$：若半径不变、质量变为原来的 $k$ 倍，则 $g$ 变为 $k$ 倍。
易错提醒｜比例式的成立前提（哪些量保持不变）必须明确，否则会出现错误对应。
🎯 口诀：多量不变才成比。

选择题排除法与量纲法基础

选择题快速作答，尤其是含参数的公式型选项。

🎯 核心思想
用单位（量纲）检验选项、用极限或特殊值代入排除、用「明显错误」快速筛掉，能在不做完整推导时锁定答案。量纲法：结果的单位必须与所求物理量一致。
  1. 先看能否用极限或特殊值排除错误选项。
  2. 对含参数的选项做量纲检验（单位是否匹配）。
  3. 对剩余选项再做定量计算确认。
🧩 典型例题
求周期表达式时，若某选项的量纲不是时间即可直接排除；令半径趋于最小看结果是否退化为已知式。
易错提醒｜排除后仍要确认最终答案唯一合理；两项都「像对」时要回到物理情境判断。
🎯 口诀：量纲一验，错误现形。

多选题取舍策略进阶

多选题，选项相互独立或只能确定其中一部分。

🎯 核心思想
多选题按正确选项给分（少选常有部分分），先把有把握的选项选上保证得分，对不确定的选项不要凭感觉全选，以免因错选而丢全分。
  1. 先挑出确定正确与确定错误的选项。
  2. 对拿不准的选项评估证据强度。
  3. 综合得分规则决定是否补选。
🧩 典型例题
四个选项中确定 $A$、$C$ 正确，$B$ 有把握、$D$ 完全不确定，则先选 $A$、$C$，$B$ 视证据决定是否补充。
易错提醒｜少选可能得部分分，多选错一个可能零分，要权衡题分与把握程度。
🎯 口诀：稳者先选，拿不准少填。

实验题规范作答与有效数字进阶

力学、电学实验的读数、作图、数据处理与误差分析。

🎯 核心思想
读数要按仪器分度值规范估读（螺旋测微器、电表需估读，游标卡尺不估读）；有效数字位数与仪器精度一致；作图用坐标纸、标清坐标轴名称与单位、用直线拟合或光滑曲线，不能画成折线。
  1. 看清仪器分度值与量程。
  2. 按规定读数（估读到分度值下一位或不估读）。
  3. 规范作图（标度、坐标轴、拟合线）。
  4. 按有效数字规则计算并写出单位。
🧩 典型例题
螺旋测微器读数 = 固定刻度 + 可动刻度 $\times 0.01\,\mathrm{mm}$（估读）；游标卡尺直接读主尺加游标，不估读。
易错提醒｜游标卡尺不估读、螺旋测微器要估读，两者规则相反；连线不能连成折线，应作直线拟合或光滑曲线。
🎯 口诀：读数估一位，有效数字配精度。

计算题分步列式得分法进阶

过程复杂的解答题、大题。

🎯 核心思想
按物理过程分段，每段先写出原始公式（字母式）再代入数据，让解题过程可见；关键连接点（共速、临界、动量与能量的关系）要明确写出，避免跳步只求结果而丢分。
  1. 分段并写明研究对象与过程。
  2. 每段写出基本定律的字母方程。
  3. 标注连接点（共速、临界、守恒关系）。
  4. 最后代入数据得结果并注明单位。
🧩 典型例题
板块题：先对滑块写 $a_1=\mu g$、对木板写 $a_2=\dfrac{\mu mg}{M}$，再写共速条件 $v=a_1t_1=a_2t_2$，分步成式。
易错提醒｜只写数字不写公式、不写单位、不说明物理过程，是失分的主因。
🎯 口诀：公式先行，过程可见。

压轴题抢分策略高阶

最后一两道综合性大题、时间紧张时的处理。

🎯 核心思想
先拿下能拿的分：画情景图、写出相关基本公式、对能确定的过程求解。压轴题的各小问往往独立，第一问通常简单，能算的先算，不会的也要写出相关方程争步骤分。
  1. 快速读题并画出情景示意图。
  2. 挑出能确定的小问先做。
  3. 写出关键模型与基本公式。
  4. 对不会的部分也写出相关方程争取步骤分。
🧩 典型例题
电磁感应压轴题第一问常是「求最大速度」，直接由 $F=F_A$ 得 $v_m=\dfrac{F(R+r)}{B^2L^2}$，先稳稳拿分。
易错提醒｜不要在难题上死磕导致简单题没时间；先易后难、控时作答。
🎯 口诀：先易后难，写式得分。

常见陷阱与审题关键词清单进阶

所有题型的审题阶段。

🎯 核心思想
审题关键词决定物理模型：「光滑」表示无摩擦，「匀速」合外力为零，「恰好」表示临界，「缓慢」表示动态平衡，「至少 / 最多」表示极值，「突然」表示瞬时状态突变。把关键词逐条翻译成物理条件。
  1. 圈出题干关键词并翻译成物理条件。
  2. 注意单位、方向与是否计入重力。
  3. 确认求解对象与取值范围。
  4. 对照模型库选择合适方法。
🧩 典型例题
「恰好不脱离轨道」对应临界：绳模型最高点满足 $mg=m\dfrac{v^2}{R}$；「缓慢拉」表示动能变化为零，用能量法而非动量。
易错提醒｜忽略「忽略空气阻力」「最高点 / 最低点」等限定；把瞬时功率当成平均功率计算。
🎯 口诀：抓关键词，定模型。

时间分配策略基础

整卷考试的节奏控制。

🎯 核心思想
按分值分配时间，先易后难，保证会做的全对；选择题、实验题速战，计算题按序推进，压轴题量力而行，最后留出检查时间。
  1. 通览全卷，估算难度分布。
  2. 先做题干熟悉、有把握的题。
  3. 为单题设定最长用时，超时先跳过。
  4. 留 $5\sim10$ 分钟回看检查。
🧩 典型例题
物理卷约 100 分、时间 75 min，平均每分钟约对应 1.3 分，选择题每题控制在 2 min 内，为计算题留足时间。
易错提醒｜卡在某道题上超时，往往牺牲了后面更容易拿到的分数，得不偿失。
🎯 口诀：先易后难，限时不恋战。
